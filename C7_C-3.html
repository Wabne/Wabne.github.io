JavaScript

JavaScript makes web pages respond to users. It can change text on the page, react to clicks, and do simple calculations. Start with basics: variables, simple functions, and handling clicks.

How to add JavaScript

Copied
<script>console.log("Hello");</script>

Core topics

  • Variables: let, const
  • Types: number, string, boolean
  • Control: if and for loops
  • Functions: declare and call simple functions

Simple example

Copied
let n = 5;
for(let i=0;i<n;i++){
  console.log(i);
}

DOM & simple events

Use document.getElementById to find an element and addEventListener to run code when the user clicks.

Good habits

  • Read error messages in the console.
  • Test small pieces of code first.

MCQs

1. Which prints a message?

(a) console.log()

(b) show()

(c) write()

(d) say()

► (a) console.log()

2. Which makes a loop that runs 3 times?

(a) for(let i=0;i<3;i++)

(b) if(i<3)

(c) while(i==3)

(d) repeat(3)

► (a) for(let i=0;i<3;i++)

3. Which is a boolean value?

(a) "yes"

(b) true

(c) 0

(d) null

► (b) true

4. Which finds an element by id?

(a) query()

(b) document.getElementById()

(c) findId()

(d) get()

► (b) document.getElementById()

5. Which declares a constant?

(a) const

(b) let

(c) var

(d) set

► (a) const

6. How do you write a comment?

(a) // comment

(b) /* comment */

(c) <!-- comment -->

(d) # comment

► (a) // comment

7. Which is an array?

(a) {1,2}

(b) [1,2]

(c) (1,2)

(d) <1,2>

► (b) [1,2]

8. Which makes a function?

(a) function name() {}

(b) def name() {}

(c) make name() {}

(d) fn name() {}

► (a) function name() {}

9. What is typeof "abc"?

(a) number

(b) string

(c) boolean

(d) object

► (b) string

10. Which stops a loop early?

(a) stop

(b) break

(c) end

(d) return

► (b) break

11. Which adds a click handler?

(a) addEventListener("click", ...)

(b) clickOn()

(c) onClick = true

(d) handleClick()

► (a) addEventListener("click", ...)

12. Which value means nothing?

(a) 0

(b) undefined

(c) "0"

(d) []

► (b) undefined

13. Which converts "10" to number?

(a) toNumber()

(b) parseInt("10")

(c) int("10")

(d) num("10")

► (b) parseInt("10")

14. Which keyword is not used in JS?

(a) let

(b) var

(c) def

(d) const

► (c) def

15. Which shows a dialog box?

(a) console.log()

(b) alert()

(c) prompt()

(d) confirm()

► (b) alert()

16. Which gets the first item of array a?

(a) a[1]

(b) a[0]

(c) a.first()

(d) a.item(0)

► (b) a[0]

17. What shows code errors?

(a) console

(b) editor only

(c) network

(d) images

► (a) console

18. Next step after basics?

(a) Learn promises and fetch

(b) Learn only HTML

(c) Stop

(d) Learn drawing

► (a) Learn promises and fetch
