Python

Python is an easy-to-read language used for programs on the computer, web backends, and learning programming concepts. It includes useful modules such as math and simple graphics with Turtle for visual learning.

How Python is used

Python runs in an interpreter. It is often used to test ideas quickly, make small games or drawings with Turtle, perform math with the math module, and build simple web services or scripts.

Key features (expanded)

  • Readable syntax and indentation-based blocks
  • Rich standard library including math, random, datetime, and turtle
  • Good for learning algorithms, simple graphics, and data tasks
  • Interactive mode and notebooks for experiments

Turtle graphics + math (simple drawing)

Use Turtle to draw shapes and use math functions for angles or positions. The example draws a polygon using math for coordinates.

Copied
import turtle, math
t = turtle.Turtle()
t.speed(5)
n = 6 # sides
r = 100
for i in range(n):
  angle = 2 * math.pi * i / n
  x = r * math.cos(angle)
  y = r * math.sin(angle)
  t.goto(x, y)
t.hideturtle()
turtle.done()

Tips for Turtle

  • Run Turtle programs in a local Python environment (many online editors do not support the graphics window).
  • Use turtle.speed() to control drawing speed and turtle.clear() to reset.
  • Combine math functions to compute positions for curves or polygons.
