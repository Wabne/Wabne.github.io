C++

C++ is a powerful, general-purpose programming language that supports procedural, object-oriented, and generic programming. It builds on C and adds classes, templates, and standard libraries (STL). C++ is widely used for systems software, games, real-time simulations, and applications that need high performance.

How C++ is used

Write source files with .cpp extension, compile with a compiler such as g++ or clang++, and run the produced executable. C++ is chosen where control, speed, and advanced abstractions (objects, templates) are required.

Key features

  • Object-oriented programming with classes and objects
  • Standard Template Library (STL) with containers and algorithms
  • Templates for generic code (functions and classes)
  • Deterministic resource management with RAII
  • Low-level control when needed (pointers, references)

}

Small examples (function, class, vector)

Copied
#include <iostream>
#include <vector>

int add(int a, int b) {
  return a + b;
}

class Point {
  public: int x, y;
  Point(int X, int Y): x(X), y(Y) {}
};

int main(){
  std::vector<Point> v;
  v.emplace_back(2, 3);
  std::cout << "Sum: " << add(4,5) << std::endl;
  std::cout << v[0].x << "," << v[0].y << std::endl;
  return 0;
}

Where C++ runs

C++ runs on desktops, servers, consoles, and embedded systems. Compile with commands like g++ file.cpp -o program or use IDEs that call the compiler for you. Use standard libraries (STL) for common data structures and algorithms.

Good practices

  • Prefer RAII: let constructors/destructors manage resources instead of manual calls.
  • Use STL containers (std::vector, std::string, std::map) instead of raw pointers when possible.
  • Keep functions and classes small and single-purpose.
  • Avoid undefined behavior: initialize variables, check bounds, and respect ownership rules.
