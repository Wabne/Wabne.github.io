Kotlin

Kotlin is a modern, easy-to-read programming language used for building Android apps and simple server programs. It works smoothly with Java libraries, helps avoid common errors with null-safety, and lets you write tasks in fewer lines.

Getting started

Save code in a file with the .kt extension. Run in an IDE (Android Studio, IntelliJ) or on the command line: kotlinc file.kt -include-runtime -d file.jar then java -jar file.jar. You can also run code in online Kotlin playgrounds for quick testing.

Basic program (Hello)

Copied
fun main() {
  println("Hello Kotlin")
}

Variables and types

Use val for values that do not change and var for values that do. Common types include Int, Double, String, and Boolean. Kotlin can often infer types for you.

Copied
val name: String = "Asha"
var age: Int = 13
println("Name: $name, Age: $age")

Functions

Declare functions with fun. Simple functions can be one-liners for clarity.

Copied
fun add(a: Int, b: Int): Int {
  return a + b
}
println(add(3, 4))

Conditionals

Use if and else to make decisions. when is a simple multi-way selector useful for many choices.

Copied
val score = 72
if (score >= 50) {
  println("Pass")
} else {
  println("Fail")
}

Loops & collections

Create lists with listOf(). Use for loops and collection helpers like filter and map to work with data simply.

Copied
val numbers = listOf(1, 2, 3, 4)
for (n in numbers) println(n)
val evens = numbers.filter { it % 2 == 0 }

Null-safety (short)

To allow a variable to be null use ?. Use the safe-call ?. and the Elvis operator ?: to give defaults and avoid errors.

Copied
var maybe: String? = null
println(maybe?.length ?: 0)

Small combined example

Copied
data class Book(val title: String, val pages: Int)
val books = listOf(Book("Math", 120), Book("Sci", 80))
val long = books.filter { it.pages >= 100 }
for (b in long) println(b.title)

Good practice tips

  • Prefer val for immutability.
  • Use descriptive names for functions and variables.
  • Handle nullable values instead of forcing non-null.
  • Test small parts of code in the Kotlin playground before combining them.

MCQs

1. Which keyword declares a read-only variable?

(a) var

(b) val

(c) let

(d) const

► (b) val

2. Which prints text in Kotlin?

(a) printline()

(b) println()

(c) echo()

(d) System.out.println()

► (b) println()

3. What file extension is used for Kotlin source?

(a) .java

(b) .kt

(c) .py

(d) .js

► (b) .kt

4. Which keyword makes a function?

(a) func

(b) def

(c) fun

(d) function

► (c) fun

5. Which builds an immutable list?

(a) mutableListOf()

(b) listOf()

(c) newList()

(d) array()

► (b) listOf()

6. What will this print if score = 72: if (score >= 50) println("Pass") else println("Fail")?

(a) Fail

(b) Pass

(c) Error

(d) Nothing

► (b) Pass

7. Which symbol marks a nullable type?

(a) *

(b) ?

(c) !

(d) $

► (b) ?

8. Which function filters a list?

(a) map()

(b) filter()

(c) sort()

(d) reduce()

► (b) filter()

9. How do you safely get the length of a nullable String s?

(a) s.length

(b) s?.length ?: 0

(c) length(s)

(d) s!! .length

► (b) s?.length ?: 0

10. Which operator is used for string templates?

(a) %

(b) $

(c) #

(d) @

► (b) $

11. What does data class provide automatically?

(a) only constructor

(b) toString(), equals(), copy()

(c) GUI

(d) database

► (b) toString(), equals(), copy()

12. Which tool compiles Kotlin to JVM bytecode?

(a) javac

(b) kotlinc

(c) gcc

(d) python

► (b) kotlinc

13. What does fun add(a:Int,b:Int) do?

(a) Declares a variable

(b) Declares a function that can add two numbers

(c) Creates a list

(d) Starts a loop

► (b) Declares a function that can add two numbers

14. Which expression gives a default when value is null?

(a) ?:

(b) ??

(c) ||

(d) &&

► (a) ?:

15. Which function transforms each item in a list?

(a) filter()

(b) map()

(c) sort()

(d) reduce()

► (b) map()

16. Which of these is a valid single-expression function?

(a) fun square(x: Int) = x * x

(b) fun square(x: Int) { x * x }

(c) def square(x) -> x * x

(d) func square(x) x * x

► (a) fun square(x: Int) = x * x

17. Kotlin can use Java libraries. True or False?

(a) True

(b) False

► (a) True

18. Best next step after learning these topics?

(a) Build a small program using lists, functions, and conditionals

(b) Stop

(c) Only study theory

(d) Skip to advanced topics

► (a) Build a small program using lists, functions, and conditionals
