Java

Java is a language used to make programs. This version is short and shows the simplest code to start learning.

Hello (one line)

Copied
public class Main{ public static void main(String[] args){ System.out.println("Hi"); } }

Quick notes

  • Save as Main.java, compile with javac Main.java, run with java Main.
  • Use System.out.println() to show text on the screen.
  • Try changing the printed text and running again.

MCQs (basic)

1. Which prints text?

(a) System.out.println()

(b) print()

(c) echo()

(d) printf()

► (a) System.out.println()

2. Which file extension?

(a) .java

(b) .py

(c) .js

(d) .c

► (a) .java

3. Which runs Java program?

(a) java Main

(b) run Main

(c) node Main

(d) python Main

► (a) java Main

4. Which creates object?

(a) new ClassName()

(b) ClassName()

(c) make Class

(d) create Class

► (a) new ClassName()

5. Which stores numbers?

(a) int

(b) String

(c) boolean

(d) char

► (a) int

6. Which prints Hi?

(a) System.out.println("Hi");

(b) print("Hi")

(c) echo "Hi"

(d) println("Hi")

► (a) System.out.println("Hi");

7. Which is entry method?

(a) main

(b) start

(c) run

(d) init

► (a) main

8. Which compiles Java?

(a) javac

(b) java

(c) gcc

(d) node

► (a) javac

9. Which shows newline?

(a) println

(b) print

(c) echo

(d) write

► (a) println

10. Which holds text?

(a) String

(b) int

(c) double

(d) boolean

► (a) String

11. How to compile file?

(a) javac Main.java

(b) java Main.java

(c) compile Main

(d) runjav Main

► (a) javac Main.java

12. Which is used for lists in advanced Java?

(a) ArrayList

(b) list

(c) vector only

(d) arraylist()

► (a) ArrayList

13. Which keyword starts a class?

(a) class

(b) structure

(c) program

(d) module

► (a) class

14. Which shows first item of array a?

(a) a[0]

(b) a[1]

(c) a.first()

(d) a.get(0)

► (a) a[0]

15. Which type holds decimals?

(a) double

(b) int

(c) String

(d) boolean

► (a) double

16. Which is used to handle errors?

(a) try/catch

(b) if/else

(c) for/while

(d) repeat

► (a) try/catch

17. Which default package is always available?

(a) java.lang

(b) java.util

(c) java.io

(d) java.net

► (a) java.lang

18. Next step?

(a) Try writing a small program that reads a number and prints it

(b) Stop

(c) Only HTML

(d) Play games

► (a) Try writing a small program that reads a number and prints it
