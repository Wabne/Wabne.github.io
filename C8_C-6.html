C

C is a general-purpose, procedural programming language used for system programming, embedded software, and performance-critical applications. It gives direct control over memory, uses a small standard library, and compiles to efficient machine code. Learning C helps you understand how programs run and how memory is managed at a low level.

How C is used

C programs are written in text files with .c extension and compiled using a C compiler (for example gcc or clang) into an executable. C is commonly used for operating systems, firmware, device drivers, and performance-sensitive libraries.

Key features

  • Procedural programming with functions and structured code
  • Manual memory management using malloc / free
  • Pointers for direct memory access and manipulation
  • Simple standard library for I/O, strings, and math

Simple structure & Hello world

Copied
#include <stdio.h>

int main(void) {
  printf("Hello, world!\\n");
  return 0;
}

Short examples (variables, loop, function)

Copied
#include <stdio.h>
#include <stdlib.h>

int add(int a, int b) {
  return a + b;
}

int main(void) {
  int i;
  for (i = 0; i < 3; ++i) {
    printf("%d\\n", i);
  }
  printf("Sum: %d\\n", add(2, 3));
  return 0;
}

Where C runs

C compilers are available on most systems (Linux, macOS, Windows via toolchains). Build commands: for example gcc file.c -o program then run ./program. Embedded toolchains compile C for microcontrollers and special hardware.

Good practices

  • Check return values from functions like malloc and fopen.
  • Avoid buffer overflows; prefer bounded functions and track sizes.
  • Free dynamically allocated memory with free() when no longer needed.
  • Initialize variables before use and keep functions short and testable.

(a) Function returning nothing

(b) Program entry function returning int and taking no args

(d) A pointer

3. Which function allocates memory?

(d) return

(a) "\n"

► (a) "\n"

(b) free()

(c) release()

(d) drop()

(a) A function

(c) A loop

(d) A type of array

► (b) A variable holding an address

(a) gcc

(b) node

(d) java

(a) int
