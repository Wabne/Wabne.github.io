C

C is a language used to write fast programs. It is useful to learn how computers store data and run instructions. This version is brief and focused on basics.

Hello world (one line)

Copied
#include <stdio.h>
int main(void){ printf("Hello\\n"); return 0; }

Things to know

  • Use printf() to show text.
  • Declare numbers with int x = 5;.
  • Compile with gcc file.c -o program and run with ./program.

MCQs

1. Which shows text?

(a) echo

(b) printf()

(c) print()

(d) say()

► (b) printf()

2. Which file extension is for C?

(a) .c

(b) .py

(c) .js

(d) .php

► (a) .c

3. How to make a variable?

(a) int x = 5;

(b) x = 5

(c) let x = 5

(d) var x = 5

► (a) int x = 5;

4. Which ends a statement?

(a) .

(b) ;

(c) :

(d) ,

► (b) ;

5. Which writes main?

(a) int main(void)

(b) main()

(c) program()

(d) start()

► (a) int main(void)

6. Which prints numbers?

(a) printf("%d", n);

(b) print(n);

(c) echo n;

(d) show(n);

► (a) printf("%d", n);

7. Which stores text?

(a) char array

(b) int

(c) float

(d) bool

► (a) char array

8. Which runs compiled program?

(a) ./a.out

(b) node file.js

(c) php file.php

(d) python file.py

► (a) ./a.out

9. Which is integer type?

(a) int

(b) str

(c) num

(d) text

► (a) int

10. How to end program?

(a) return 0;

(b) stop;

(c) end;

(d) finish;

► (a) return 0;

11. Which header shows printf?

(a) <stdio.h>

(b) <math.h>

(c) <time.h>

(d) <string.h>

► (a) <stdio.h>

12. Which symbol begins a comment (single-line)?

(a) //

(b) <!--

(c) #

(d) ##

► (a) //

13. Which reads input from user?

(a) scanf()

(b) input()

(c) read()

(d) get()

► (a) scanf()

14. Which shows newline inside string?

(a) "\n"

(b) "/n"

(c) "\\n"

(d) "
"

► (a) "\n"

15. Which prints a character?

(a) printf("%c", ch);

(b) printf("%d", ch);

(c) printf("%s", ch);

(d) cout << ch;

► (a) printf("%c", ch);

16. Which declares array of three ints?

(a) int a[3];

(b) a = [];

(c) list(3)

(d) array(3)

► (a) int a[3];

17. Which prints string s?

(a) printf("%s", s);

(b) print(s);

(c) echo s;

(d) cout << s;

► (a) printf("%s", s);

18. What to learn next?

(a) Practice simple functions and arrays

(b) Stop

(c) Only images

(d) Learn cooking

► (a) Practice simple functions and arrays
