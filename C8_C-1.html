HTML

HTML (HyperText Markup Language) is the language used to create web pages. It tells a web browser how to show text, images, and other content. Learning HTML helps you build simple websites and understand how the web works.

Why HTML Matters

HTML is the foundation of every website. It helps structure content so browsers, search engines, and assistive tools can read it. Once you know HTML you can add style with CSS and interactivity with JavaScript.

Basic parts of an HTML page

  • Doctype – tells the browser this is an HTML5 page
  • <html> – the root element that contains the page
  • <head> – meta information (title, charset)
  • <title> – name shown in the browser tab
  • <meta> – character set and viewport settings
  • <body> – visible content of the page

Structure of an HTML document

Copied
<!doctype html>
  <html lang="en">
    <head>
      <meta charset="utf-8">
      <meta name="viewport" content="width=device-width,initial-scale=1">
      <title>My Page</title>
    </head>
    <body>
      <h1>Welcome</h1>
      <p>This is a simple HTML page.</p>
    </body>
  </html>

Common tags and uses

  • <h1>…</h1> to <h6>…</h6> — headings (use one <h1> per page)
  • <p> — paragraph text
  • <ul> / <ol> / <li> — lists
  • <div> and <span> — generic containers for grouping
  • <strong> and <em> — important and emphasized text

Images and short note on links

Images use the <img> tag. For this course we generally avoid using external links; focus on local files and learning structure first.

Forms (short note)

Forms collect user input with <form> and <input> tags. Often the action attribute is left empty in classroom examples because processing is done later (for learning we show the fields only; real sites set action to a server URL).

Semantic tags and accessibility (in code)

Copied
<header><h1>Site Name</h1></header>
<nav><!-- navigation items --></nav>
<main><section><p>Main content here.</p></section></main>
<footer><p>Contact info</p></footer>

Linking CSS

To add styles use <link rel="stylesheet" href="style.css"> in the <head> so CSS is applied to the page.

Copied
@media (max-width: 768px){
  .page {
    font-size: 1.1rem;
    flex-direction: column;
  }
}
@media (min-width: 769px){
  .page {
    font-size: 1.4rem;
    flex-direction: row;
  }
}

Top editors and tools

  • VS Code — beginner-friendly editor
  • Browser DevTools — inspect and test HTML live

How HTML helps everyday

  • Build simple web pages and school projects
  • Share content like reports and portfolios
  • Understand how websites are made

Drawbacks / cautions

  • Incorrect HTML can break page layout
  • Always test pages in different browsers
  • Be careful with untrusted HTML from others (security)

What’s next

After HTML learn CSS for styling and JavaScript for interactivity. These three together make modern web pages.

MCQs

1. What does HTML stand for?

(a) HyperText Markup Language

(b) HighTool Markup List

(c) Hyperlink Text Management

(d) Home Tool Markup

► (a) HyperText Markup Language

2. Which tag holds the visible content of a page?

(a) <head>

(b) <body>

(c) <meta>

(d) <title>

► (b) <body>

3. Which tag is used for a top-level heading?

(a) <p>

(b) <h1>

(c) <div>

(d) <span>

► (b) <h1>

4. How do you show an image in HTML?

(a) <image>

(b) <img>

(c) <picture>

(d) <figure>

► (b) <img>

5. Where does <title> appear?

(a) In the browser tab

(b) On the page body

(c) In CSS file

(d) In JavaScript console

► (a) In the browser tab

6. What is the correct doctype for HTML5?

(a) <!DOCTYPE HTML>

(b) <!doctype html>

(c) <!HTML5>

(d) <!doctype html5>

► (b) <!doctype html>

7. Which tag groups list items?

(a) <li>

(b) <ul>

(c) <p>

(d) <img>

► (b) <ul>

8. Which tag is used for a paragraph?

(a) <par>

(b) <pp>

(c) <p>

(d) <para>

► (c) <p>

9. To link a CSS file you use:

(a) <script src="style.css">

(b) <link rel="stylesheet" href="style.css">

(c) <css src="style.css">

(d) <style src="style.css">

► (b) <link rel="stylesheet" href="style.css">

10. What attribute describes an image for accessibility?

(a) title

(b) src

(c) alt

(d) desc

► (c) alt

11. Which tag is semantic for the page footer?

(a) <bottom>

(b) <footer>

(c) <div class="footer">

(d) <end>

► (b) <footer>

12. Which tag is used inside <head> for metadata?

(a) <meta>

(b) <header>

(c) <body>

(d) <article>

► (a) <meta>

13. Which tag is best for grouping inline text?

(a) <div>

(b) <span>

(c) <section>

(d) <article>

► (b) <span>

14. Which tag would you use for main content area?

(a) <aside>

(b) <main>

(c) <nav>

(d) <footer>

► (b) <main>

15. Why escape < and > in code examples?

(a) To hide them from the browser so they show as text

(b) Because they are not allowed in HTML

(c) To make the page load faster

(d) To change their color

► (a) To hide them from the browser so they show as text

16. Which element should you use for a navigation block?

(a) <nav>

(b) <navy>

(c) <menu>

(d) <links>

► (a) <nav>

17. What does the viewport meta tag help with?

(a) Make page responsive on mobile

(b) Add images

(c) Run JavaScript

(d) Store cookies

► (a) Make page responsive on mobile

18. Which tag should you use for the page title shown in search results?

(a) <h1>

(b) <title>

(c) <meta>

(d) <header>

► (b) <title>
