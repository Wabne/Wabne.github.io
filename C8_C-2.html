CSS

CSS (Cascading Style Sheets) describes how HTML elements appear on screen. It controls layout, colors, spacing, fonts, and responsive adjustments. Learning CSS makes web pages clearer, more attractive, and easier to maintain.

Why CSS Matters

CSS separates presentation from structure. This improves maintainability, accessibility, and consistency across pages. It also lets a single stylesheet style many pages and adapt the layout to different devices.

Basic parts of CSS

  • Selector — chooses which HTML elements to style
  • Property — the aspect to change (color, margin, font-size)
  • Value — the setting for a property (e.g., red, 16px)
  • Rule (declaration) — selector + { property: value; }

CSS syntax example

Copied
/* selector { property: value; } */
.title {
  font-size: 24px;
  color: #333333;
  margin-bottom: 10px;
}

Selectors (common)

  • Type selector — e.g., p styles all paragraphs
  • Class selector — e.g., .card used on elements with that class
  • ID selector — e.g., #main targets one element
  • Descendant/child selectors — target elements inside others
  • Pseudo-classes — e.g., :hover for mouse-over styling

Colors, fonts and text

Use named colors, hex codes, or RGB for color. Choose readable font sizes and set line-height to improve legibility.

Copied
p {
  color: #2a2a2a;
  font-family: Arial, sans-serif;
  line-height: 1.5;
}

The box model

Every element is a rectangle made of content, padding, border, and margin. Understanding the box model is essential for layout and spacing.

Copied
.box {
  padding: 10px;
  border: 1px solid #ccc;
  margin: 20px;
  width: 200px;
}

Layout basics

  • display — block, inline, inline-block, none
  • position — static, relative, absolute, fixed
  • flexbox — a simple way to create rows and columns
  • grid — two-dimensional layout system for complex designs

Responsive design & media queries

Use media queries to change styles based on screen width so pages work on phones and desktops.

Copied
@media (max-width: 600px){
  .nav {
    display: none;
  }
}

Classes, IDs and specificity

Rules with higher specificity override others. ID selectors are stronger than class selectors; inline styles are strongest. Keep specificity low for easier maintenance.

Pseudo-classes and interactions

Use pseudo-classes like :hover and :focus to change styles on user interaction without JavaScript.

Copied
a:hover {
  color: blue;
  text-decoration: underline;
}

Performance and organization

  • Keep CSS files small and modular
  • Use external stylesheet links for caching
  • Minimize expensive selectors and large images

Tools and editors

  • VS Code — live preview and extensions
  • Browser DevTools — test styles and layout in real time

What’s next

After CSS learn responsive patterns, advanced layout (Grid), and how CSS and JavaScript interact for dynamic interfaces.

MCQs

1. What does CSS stand for?

(a) Computer Style Sheets

(b) Cascading Style Sheets

(c) Creative Style System

(d) Color Style Syntax

► (b) Cascading Style Sheets

2. Which property changes text color?

(a) font-size

(b) color

(c) background

(d) display

► (b) color

3. How do you include an external CSS file?

(a) <script src="style.css">

(b) <link rel="stylesheet" href="style.css">

(c) <css href="style.css">

(d) <style src="style.css">

► (b) <link rel="stylesheet" href="style.css">

4. Which property adds space inside an element?

(a) margin

(b) padding

(c) border

(d) width

► (b) padding

5. Which display value makes elements line up horizontally?

(a) block

(b) inline

(c) grid

(d) flex

► (d) flex

6. What does the box model include?

(a) content, padding, border, margin

(b) text, image

(c) selector and declaration

(d) head and body

► (a) content, padding, border, margin

7. Which selector targets elements by class?

(a) #header

(b) .card

(c) div

(d) *

► (b) .card

8. How do you write a comment in CSS?

(a) // comment

(b) /* comment */

(c) <!-- comment -->

(d) # comment

► (b) /* comment */

9. Which property sets the font size?

(a) font-weight

(b) font-size

(c) text-size

(d) size

► (b) font-size

10. Which pseudo-class applies on mouse-over?

(a) :active

(b) :visited

(c) :hover

(d) :target

► (c) :hover

11. What does @media (max-width: 600px) do?

(a) Adds an image

(b) Applies styles when viewport is at most 600px wide

(c) Runs JavaScript

(d) Changes HTML structure

► (b) Applies styles when viewport is at most 600px wide

12. Which property creates a border?

(a) border

(b) outline

(c) stroke

(d) frame

► (a) border

13. Which unit is relative to the font size?

(a) px

(b) em

(c) cm

(d) in

► (b) em

14. Where should you put link to CSS for best caching?

(a) inline in body

(b) in head as external file

(c) in JavaScript

(d) inside image tag

► (b) in head as external file

15. Which property changes element visibility layout but keeps space?

(a) display: none;

(b) visibility: hidden;

(c) opacity: 0;

(d) hidden: true;

► (b) visibility: hidden;

16. Which CSS rule is strongest?

(a) element selector

(b) class selector

(c) ID selector

(d) inline style

► (d) inline style

17. Which layout system is best for two-dimensional grids?

(a) flexbox

(b) grid

(c) float

(d) inline-block

► (b) grid

18. What is a common way to reduce CSS file size for production?

(a) Add comments

(b) Minify the CSS

(c) Use extra spaces

(d) Duplicate rules

► (b) Minify the CSS
