HTML

HTML is the language used to make web pages. It uses tags to tell a browser how to show text and basic content.

Why HTML

HTML structures the content of websites so browsers can display it. Learning it helps you make simple pages and school projects.

Basic parts

  • Doctype — tells browser this is HTML5
  • <html>, <head>, <title>, <body>

Document example

Copied
<!doctype html>
<html>
  <head><title>Page</title></head>
  <body><h1>Hello</h1></body>
</html>

Common tags

  • <h1> heading, <p> paragraph
  • <ul> / <li> — lists

Forms (note)

Forms are shown for fields only; examples often leave action empty in lessons so students focus on fields and layout.

Linking CSS

Copied
<link rel="stylesheet" href="style.css">

Tools

  • Simple editor (Notepad or VS Code)
  • Browser to open the .html file

MCQs

1. Which tag shows a paragraph?

(a) <h1>

(b) <p>

(c) <img>

(d) <ul>

► (b) <p>

2. Which tag starts an HTML document?

(a) <!doctype html>

(b) <title>

(c) <body>

(d) <meta>

► (a) <!doctype html>

3. Where does the page title go?

(a) <head>

(b) <body>

(c) <footer>

(d) <nav>

► (a) <head>

4. How do you show text as important?

(a) <b>

(b) <strong>

(c) <i>

(d) <small>

► (b) <strong>

5. Which tag holds a list item?

(a) <li>

(b) <ul>

(c) <ol>

(d) <dl>

► (a) <li>

6. Which attribute is used for image file?

(a) href

(b) src

(c) alt

(d) title

► (b) src

7. Which tag wraps visible page content?

(a) <head>

(b) <body>

(c) <meta>

(d) <link>

► (b) <body>

8. Which tag is used to show a heading?

(a) <h1>

(b) <hr>

(c) <img>

(d) <code>

► (a) <h1>

9. What does <link rel="stylesheet"> do?

(a) Adds JavaScript

(b) Adds CSS file

(c) Adds image

(d) Adds meta data

► (b) Adds CSS file

10. Which tag is NOT used for text?

(a) <p>

(b) <h2>

(c) <img>

(d) <strong>

► (c) <img>

11. Which tag helps accessibility for images?

(a) src

(b) alt

(c) id

(d) class

► (b) alt

12. Which tag is used for a block of content?

(a) <span>

(b) <div>

(c) <img>

(d) <li>

► (b) <div>

13. How do you write a comment in HTML?

(a) // comment

(b) <!-- comment -->

(c) /* comment */

(d) # comment

► (b) <!-- comment -->

14. Which tag is for a small heading?

(a) <h6>

(b) <h0>

(c) <h7>

(d) <h1>

► (a) <h6>

15. Which tag shows a horizontal rule?

(a) <hr>

(b) <br>

(c) <break>

(d) <line>

► (a) <hr>

16. Which tag is used for a section of content?

(a) <section>

(b) <article>

(c) <footer>

(d) <head>

► (a) <section>

17. To create a line break you use:

(a) <br>

(b) <break>

(c) <lb>

(d) <br/>

► (a) <br>

18. Which is required in the head for mobile-friendly pages?

(a) <meta name="viewport" ...>

(b) <meta name="author">

(c) <title>

(d) <link>

► (a) <meta name="viewport" ...>
