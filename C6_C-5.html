Python

Python is a simple language for writing programs that run on a computer. It is good for beginners and useful for small tasks and math practice.

Hello world (one line)

Copied
print("Hello!")

Basic math module examples

Copied
import math
print(math.pi)
print(math.sqrt(16))

Small examples & tips

  • Use print() to show results.
  • Create variables like x = 5 and do print(x + 3).
  • Try the math examples in the Python shell or a simple file.

MCQs

1. Which prints text?

(a) echo()

(b) print()

(c) show()

(d) say()

► (b) print()

2. Which imports math?

(a) import math

(b) use math

(c) include math

(d) require math

► (a) import math

3. What does math.sqrt(16) return?

(a) 4

(b) 16

(c) 2

(d) 8

► (a) 4

4. Which is the value of pi from math?

(a) math.pi

(b) pi()

(c) PI

(d) math.Pi

► (a) math.pi

5. How to assign 5 to x?

(a) x = 5

(b) let x = 5

(c) var x = 5

(d) set x 5

► (a) x = 5

6. Which adds numbers?

(a) +

(b) .

(c) &

(d) concat()

► (a) +

7. Which returns integer from text "7"?

(a) int("7")

(b) parseInt("7")

(c) number("7")

(d) toInt("7")

► (a) int("7")

8. Which gives cosine of 0?

(a) math.cos(0)

(b) math.sin(0)

(c) cos(0)

(d) math.tan(0)

► (a) math.cos(0)

9. Which creates a list?

(a) [1,2]

(b) {1,2}

(c) (1,2)

(d) <1,2>

► (a) [1,2]

10. Which gets first item of list a?

(a) a[0]

(b) a[1]

(c) first(a)

(d) a.get(0)

► (a) a[0]

11. Which converts "3.5" to float?

(a) float("3.5")

(b) int("3.5")

(c) number("3.5")

(d) toFloat("3.5")

► (a) float("3.5")

12. Which loop counts three times?

(a) for i in range(3)

(b) while i == 3

(c) repeat 3

(d) do 3

► (a) for i in range(3)

13. Which shows length of "abc"?

(a) len("abc")

(b) size("abc")

(c) length("abc")

(d) "abc".len()

► (a) len("abc")

14. Which reads a number from input?

(a) int(input())

(b) read()

(c) get()

(d) inputNumber()

► (a) int(input())

15. Which shows pi?

(a) math.pi

(b) pi()

(c) PI

(d) math.PI

► (a) math.pi

16. Which makes a function?

(a) def name():

(b) function name()

(c) fn name()

(d) make name()

► (a) def name():

17. Which is true/false type?

(a) bool

(b) int

(c) str

(d) list

► (a) bool

18. What to learn next?

(a) Practice small programs and math functions

(b) Stop

(c) Only images

(d) Learn cooking

► (a) Practice small programs and math functions
