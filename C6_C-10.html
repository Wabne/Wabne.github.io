Kotlin

Kotlin is a modern, easy-to-read programming language used for building Android apps and simple server programs.

Hello — one line

Copied
fun main(){ println("Hi") }

Simple variables

Use val when a value does not change and var when it does. Types like Int and String are common but you can often skip writing the type because Kotlin guesses it.

Copied
val city = "Mumbai"
var year = 2025
println(city)

Tiny function

A function does a small job. This one finds the square of a number.

Copied
fun square(n: Int): Int {
  return n * n
}
println(square(5))

Short loop

Use a for loop to repeat a simple action.

Copied
for (i in 1..3) println(i)

Very short notes

  • println() shows text on the screen.
  • val = value that does not change; var = value that can change.
  • Save files with .kt and run in a Kotlin playground or IDE.

MCQs (easy)

1. Which prints text?

(a) echo()

(b) println()

(c) show()

(d) output()

► (b) println()

2. Which starts a Kotlin program?

(a) start()

(b) run()

(c) main()

(d) begin()

► (c) main()

3. Which makes a value that cannot change?

(a) var

(b) val

(c) let

(d) const

► (b) val

4. How do you write a one-line loop that prints 1 to 3?

(a) for (i in 1..3) println(i)

(b) repeat 3

(c) loop 3

(d) while 3

► (a) for (i in 1..3) println(i)

5. What keyword starts a function?

(a) fun

(b) func

(c) def

(d) function

► (a) fun

6. What does square(5) give?

(a) 10

(b) 25

(c) 5

(d) 0

► (b) 25

7. Which is a number type?

(a) Text

(b) Int

(c) Word

(d) Char

► (b) Int

8. Which symbol is used to include variables inside strings?

(a) #

(b) %

(c) $

(d) &

► (c) $

9. Which file ending is for Kotlin?

(a) .java

(b) .kt

(c) .py

(d) .txt

► (b) .kt

10. Which keyword lets a value change?

(a) val

(b) var

(c) let

(d) const

► (b) var

11. Which prints the city in the example?

(a) println(city)

(b) print(city)

(c) echo city

(d) write city

► (a) println(city)

12. How do you make a loop run three times?

(a) for (i in 1..3)

(b) repeat 3

(c) while 3

(d) do 3

► (a) for (i in 1..3)

13. Which prints "Hi" in the Hello example?

(a) println("Hi")

(b) echo "Hi"

(c) printline("Hi")

(d) show("Hi")

► (a) println("Hi")

14. Which keyword do you use to store a name that does not change?

(a) var

(b) val

(c) let

(d) const

► (b) val

15. Which example shows a function?

(a) fun square(n: Int): Int { return n * n }

(b) for (i in 1..3) println(i)

(c) val city = "Mumbai"

(d) println("Hi")

► (a) fun square(n: Int): Int { return n * n }

16. Which is easiest to try code quickly?

(a) Kotlin playground

(b) Build a car

(c) Print on paper

(d) Install heavy tools

► (a) Kotlin playground

17. After these lessons, a good practice is to:

(a) Try writing a small program that adds two numbers

(b) Stop

(c) Only watch videos

(d) Do nothing

► (a) Try writing a small program that adds two numbers

18. Best short summary of Kotlin here?

(a) Hard and long

(b) Simple and useful

(c) Only for games

(d) Only for robots

► (b) Simple and useful
