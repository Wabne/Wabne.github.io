Python

Python is a high-level, general-purpose language used for scripting, web backends, data work, automation, and quick programs. It emphasizes readable code and a large standard library. Python runs on an interpreter and is suitable for both small scripts and larger projects.

How Python is used

Python code runs on the system interpreter. It is used for web servers, command-line tools, data analysis, automation, and simple GUI or graphics tasks (for example, Turtle for learning).

Key features

  • Readable, concise syntax
  • Dynamic typing and automatic memory management
  • Large standard library (math, datetime, os, etc.)
  • Many third-party packages for web, data, and more

Simple structure & Hello world

Copied
print("Hello, world!")

Using the math module (short)

Copied
import math
print(math.pi)
print(math.sqrt(25))

Small I/O & functions

Copied
def add(a, b):
  return a + b
n = int(input("Enter a number: "))
print("Double:", add(n, n))

Where Python runs

Run scripts with the system Python interpreter (for example python3 file.py), use virtual environments for projects, and use tools like Jupyter notebooks for interactive data work.

Good practices

  • Keep functions small and focused
  • Use virtual environments for dependencies
  • Handle exceptions and validate inputs
  • Follow PEP8 naming and style conventions

MCQs

1. How do you print text in Python?

(a) echo()

(b) print()

(c) console.log()

(d) write()

► (b) print()

2. Which is the correct file extension for Python?

(a) .py

(b) .js

(c) .php

(d) .html

► (a) .py

3. Which module gives math constants and functions?

(a) math

(b) utils

(c) calc

(d) numbers

► (a) math

4. What does math.sqrt(25) return?

(a) 5

(b) 25

(c) 0

(d) 10

► (a) 5

5. Which keyword defines a function?

(a) def

(b) function

(c) func

(d) lambda

► (a) def

6. How to get pi from math?

(a) math.pi

(b) math.Pi()

(c) pi()

(d) math.PI

► (a) math.pi

7. Which runs a Python file?

(a) python3 file.py

(b) node file.js

(c) php file.php

(d) java file.java

► (a) python3 file.py

8. Which is true about Python typing?

(a) Static typing required

(b) Dynamically typed

(c) No types at all

(d) Must declare types

► (b) Dynamically typed

9. Which creates a list?

(a) [1,2]

(b) {1,2}

(c) (1,2)

(d) <1,2>

► (a) [1,2]

10. Which statement handles errors?

(a) try/except

(b) catch

(c) on error

(d) handle

► (a) try/except

11. Which installs Python packages?

(a) pip

(b) npm

(c) composer

(d) gem

► (a) pip

12. How to return a value from function?

(a) return

(b) yield

(c) give

(d) send

► (a) return

(a) python shell
