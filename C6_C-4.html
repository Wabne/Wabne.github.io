PHP

PHP is a language that runs on a server to make web pages show different content. It prints text, works with simple data, and helps pages talk to databases.

Hello World (one line)

Copied
<?php echo "Hello!"; ?>

Things to know

  • Use echo to show text.
  • Store values in variables like $x = 5;.
  • Try small examples in a test server or built-in server.

MCQs

1. What command shows text in PHP?

(a) show()

(b) echo

(c) printText()

(d) write()

► (b) echo

2. Which marks PHP code start?

(a) <?php

(b) <start>

(c) <php>

(d) <!--php-->

► (a) <?php

3. How to make a variable?

(a) var x = 5;

(b) $x = 5;

(c) x := 5

(d) let x = 5;

► (b) $x = 5;

4. Which joins two words?

(a) +

(b) .

(c) &

(d) concat()

► (b) .

5. Where does PHP run?

(a) Browser

(b) Server

(c) Printer

(d) Camera

► (b) Server

6. Which makes a pop-up?

(a) alert()

(b) echo

(c) prompt()

(d) confirm()

► (b) echo

7. Which shows the first letter length?

(a) strlen()

(b) size()

(c) length()

(d) count()

► (a) strlen()

8. Which symbol starts a variable?

(a) $

(b) #

(c) @

(d) &

► (a) $

9. Which file extension usually used?

(a) .php

(b) .css

(c) .jpg

(d) .txt

► (a) .php

10. Which adds numbers?

(a) .

(b) +

(c) &

(d) concat()

► (b) +

11. Which makes code reusable?

(a) function

(b) style

(c) image

(d) link

► (a) function

12. Which reads form data sent by user (POST)?

(a) $_POST

(b) $_GET

(c) $_DATA

(d) $_FORM

► (a) $_POST

13. Which makes text uppercase?

(a) strtoupper()

(b) toUpper()

(c) upper()

(d) up()

► (a) strtoupper()

14. Which checks length of string?

(a) strlen()

(b) size()

(c) count()

(d) length()

► (a) strlen()

15. Which combines text and number?

(a) "Age: " . $age

(b) "Age: " + $age

(c) "Age: " & $age

(d) "Age: " concat $age

► (a) "Age: " . $age

16. Which shows all errors during testing?

(a) error_reporting(E_ALL);

(b) show_errors(true);

(c) debug_on();

(d) print_errors();

► (a) error_reporting(E_ALL);

17. Which stores many values?

(a) array

(b) string

(c) number

(d) boolean

► (a) array

18. Which to learn next?

(a) Forms and databases

(b) Only images

(c) Stop now

(d) Draw pictures

► (a) Forms and databases
