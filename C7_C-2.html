CSS

CSS (Cascading Style Sheets) defines how HTML elements appear. It controls colors, spacing, fonts, sizing, layout, and responsive behavior. CSS keeps presentation separate from structure so a single stylesheet can style many pages consistently.

Selectors and how to target elements

Selectors choose which elements receive styles. Common selector types and examples:

  • Type selector — p { ... } targets all paragraph elements
  • Class selector — .note { ... } targets elements with class="note"
  • ID selector — #main { ... } targets the element with id="main"
  • Descendant selector — nav a { ... } targets <a> inside <nav>
  • Pseudo-class — a:hover { ... } applies when the mouse is over a link

Specificity and order

More specific selectors override less specific ones. ID selectors are stronger than class selectors, and inline styles override external rules. When specificity ties, later rules win.

Linking CSS

Place the stylesheet link in the document head so styles load before rendering:

Copied
<link rel="stylesheet" href="style.css">

Basic CSS syntax & examples

Copied
/* selector { property: value; } */
p {
  font-size: 16px;
  color: #333;
}
.note {
  background: #f8f8f8;
  padding: 8px;
}

The box model

Every element is a box: content, padding, border, margin. Use padding for inner space and margin for space between elements.

Copied
.card {
  padding: 12px;
  border: 1px solid #ddd;
  margin: 16px 0;
  box-sizing: border-box;
}

Layout basics (flexbox & grid)

Flexbox is suitable for one-dimensional layouts (rows or columns). Grid is for two-dimensional layouts. Use the simplest tool that meets the design need.

Copied
.row {
  display: flex;
  gap: 12px;
}
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}

Responsive design & media queries

Adjust styles for different screen widths using media queries so layouts remain usable on phones and tablets.

Copied
@media (max-width: 600px){
  .row {
    flex-direction: column;
  }
}

Pseudo-classes and simple interactions

Use pseudo-classes like :hover and :focus to improve usability. Avoid relying on hover-only interactions for touch devices.

Organization and performance

  • Place reusable styles in external files for caching.
  • Keep selectors simple and avoid very deep descendant chains.
  • Minify CSS for production to reduce file size.

Tools

  • Editor: VS Code or a simple text editor
  • Browser DevTools to inspect and test styles

MCQs

1. Which selector targets elements by class?

(a) #name

(b) .name

(c) name

(d) *name

► (b) .name

2. What does box-sizing: border-box; do?

(a) Removes borders

(b) Includes padding and border in the element's width

(c) Hides overflow

(d) Adds margin

► (b) Includes padding and border in the element's width

3. Which property controls space between lines of text?

(a) letter-spacing

(b) line-height

(c) text-indent

(d) word-spacing

► (b) line-height

4. How do you hide an element but keep its layout space?

(a) display: none;

(b) visibility: hidden;

(c) opacity: 0;

(d) remove: true;

► (b) visibility: hidden;

5. Which is the correct way to link an external CSS file?

(a) <script src="style.css">

(b) <link rel="stylesheet" href="style.css">

(c) <style src="style.css">

(d) <css src="style.css">

► (b) <link rel="stylesheet" href="style.css">

6. Which layout method is best for a row of items that should wrap?

(a) grid

(b) flexbox

(c) table

(d) float

► (b) flexbox

7. What does the :hover pseudo-class apply to?

(a) Keyboard focus

(b) Mouse-over state

(c) Page load

(d) Print styles

► (b) Mouse-over state

8. Which selector is most specific?

(a) p

(b) .note

(c) #main

(d) *

► (c) #main

9. Which property sets the font family?

(a) font-style

(b) font-weight

(c) font-family

(d) font-size

► (c) font-family

10. What is a safe practice for performance?

(a) Use very deep selectors

(b) Keep CSS modular and reuse styles

(c) Inline large CSS in every page

(d) Add many unused rules

► (b) Keep CSS modular and reuse styles

11. Which unit is relative to the parent size?

(a) em

(b) px

(c) %

(d) cm

► (c) %

12. How is a comment written in CSS?

(a) // comment

(b) /* comment */

(c) <!-- comment -->

(d) # comment

► (b) /* comment */

13. Which property controls element order in flexbox?

(a) order

(b) position

(c) display

(d) float

► (a) order

14. Which rule helps mobile layout at small widths?

(a) @media (min-width: 1200px)

(b) @media (max-width: 600px)

(c) @supports (grid)

(d) @font-face

► (b) @media (max-width: 600px)

15. What property adds space inside an element?

(a) margin

(b) padding

(c) border

(d) gap

► (b) padding

16. Which is true about display: none;?

(a) The element is hidden and takes no space

(b) The element is hidden but space remains

(c) The element becomes transparent

(d) The element is converted to inline

► (a) The element is hidden and takes no space

17. Which layout system is best for two-dimensional placement?

(a) float

(b) flexbox

(c) grid

(d) inline

► (c) grid

18. What should you learn after basic CSS?

(a) Advanced layout (Grid) and responsive design

(b) Painting

(c) Cooking

(d) Office tools

► (a) Advanced layout (Grid) and responsive design
