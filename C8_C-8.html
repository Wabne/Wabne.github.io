C#

C# (C-sharp) is a modern, object-oriented programming language that runs on the .NET runtime. It is used to build desktop apps, web backends, APIs, and games (Unity). C# combines strong typing, clear syntax, and tools (dotnet CLI, Visual Studio) to produce reliable applications quickly.

How C# is used

Write source files with .cs extension, build with the dotnet CLI or an IDE, and run on the .NET runtime. C# compiles to an intermediate language (IL) which the runtime executes. Typical uses: web services (ASP.NET), desktop apps, tools, and game scripting.

Key features

  • Object-oriented (classes, inheritance, interfaces)
  • Garbage-collected memory (no manual free)
  • Features: properties, events, LINQ, async/await
  • Large standard libraries and NuGet packages

Simple structure & Hello world

Copied
using System;

class Program {
  static void Main() {
    Console.WriteLine("Hello, world!");
  }
}

Simple class & list example

Copied
using System;
using System.Collections.Generic;

class Person { public string Name { get; set; } }

class Program {
  static void Main() {
    var list = new List<Person> { new Person { Name = "A" } };
    Console.WriteLine(list[0].Name);
  }
}

Async basics (short)

Asynchronous code (async/await) helps run tasks without blocking the main thread. Use for I/O, network calls, or long-running work.

Copied
using System;
using System.Threading.Tasks;

class Program {
  static async Task Main() {
    await Task.Delay(100);
    Console.WriteLine("Async done");
  }
}

Good practices

  • Use strong typing and meaningful names
  • Prefer properties over public fields for classes
  • Use exceptions (try/catch) for error handling and dispose resources via using
  • Use dotnet new, dotnet build, and dotnet run for projects
