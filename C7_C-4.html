PHP

PHP is a language used on the server to make web pages change depending on data or user actions. It builds HTML that the browser shows and can read or write data from a database.

How PHP works

Server runs PHP code and sends the resulting HTML to the browser. PHP files usually have the .php extension.

Features

  • Generates HTML dynamically
  • Works with databases
  • Simple syntax for printing text

Hello world (simple)

Copied
<?php echo "Hello, world!"; ?>

Small example (variable)

Copied
<?php $name = "A"; echo "Hi " . $name; ?>

MCQs

1. Which file extension is common for PHP files?

(a) .html

(b) .php

(c) .css

(d) .txt

► (b) .php

2. How to print text?

(a) echo

(b) printText

(c) console.log

(d) show

► (a) echo

3. Which joins strings in PHP?

(a) +

(b) .

(c) &

(d) concat()

► (b) .

4. Which shows Hello world?

(a) <?php echo "Hello"; ?>

(b) echo "Hello"

(c) printf("Hello")

(d) All of the above (with correct syntax)

► (d) All of the above (with correct syntax)

5. Which stores text in PHP?

(a) string

(b) number

(c) boolean

(d) array

► (a) string

6. What does the dot operator do?

(a) Multiply

(b) Concatenate strings

(c) Divide

(d) Compare

► (b) Concatenate strings

7. Is PHP used to access databases?

(a) Yes

(b) No

(c) Only on phones

(d) Only for styles

► (a) Yes

8. Which prints a variable $name?

(a) echo $name;

(b) print $name;

(c) Both (a) and (b)

(d) None

► (c) Both (a) and (b)

9. Which starts PHP code?

(a) <?php

(b) <?>

(c) <php?>

(d) <!-- php -->

► (a) <?php

10. Which combines text and variable?

(a) "Hi $name"

(b) "Hi " . $name

(c) Both are valid forms

(d) None

► (c) Both are valid forms

11. Which is used to include code from another file?

(a) include()

(b) import()

(c) link()

(d) requireCSS()

► (a) include()

12. Which is a correct comment?

(a) // comment

(b) /* comment */

(c) # comment

(d) All of the above

► (d) All of the above

13. Which can run PHP code?

(a) Browser only

(b) Server (PHP interpreter)

(c) Image viewer

(d) Text editor

► (b) Server (PHP interpreter)

14. Which is used to make a function?

(a) function name() { }

(b) def name() { }

(c) fn name() { }

(d) make name() { }

► (a) function name() { }

15. Which superglobal has server info?

(a) $_SERVER

(b) $_POST

(c) $_GET

(d) $_FILES

► (a) $_SERVER

16. Which shows the first item of an array $a?

(a) $a[0]

(b) $a[1]

(c) $a.first()

(d) $a->first

► (a) $a[0]

17. Which returns true/false?

(a) string

(b) boolean

(c) number

(d) array

► (b) boolean

18. Next useful topic after basics?

(a) Database queries and forms

(b) Only styling

(c) Image editing

(d) Nothing

► (a) Database queries and forms
