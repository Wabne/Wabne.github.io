CSS

CSS controls how HTML looks. Below is slightly simplified content that preserves key topics: selectors, linking, box model, layout, responsive design, and examples suitable for practice and MCQs.

Selectors and examples

  • Type selector: h1 { ... }
  • Class selector: .help { ... }
  • ID selector: #top { ... }
  • Combined selector: ul li { ... }

Linking CSS (quick)

Copied
<link rel="stylesheet" href="style.css">

Simple examples

Copied
h1 {
  color: #d00;
  font-size: 20px;
}
.box {
  padding: 10px;
  border: 1px solid #ccc;
}

Box model (short)

Use padding for inner spacing and margin for outer spacing. Borders sit between padding and margin.

Responsive note

Copied
@media (max-width: 480px){
  .menu { display: none; }
}

MCQs

1. Which symbol starts a class selector?

(a) #

(b) .

(c) *

(d) $

► (b) .

2. Which property sets the font size?

(a) font-weight

(b) font-family

(c) font-size

(d) text-size

► (c) font-size

3. How do you include CSS in the head?

(a) <script src="style.css">

(b) <link rel="stylesheet" href="style.css">

(c) <style src="style.css">

(d) <css src="style.css">

► (b) <link rel="stylesheet" href="style.css">

4. What part is inside an element's box?

(a) margin

(b) padding

(c) outside

(d) gap

► (b) padding

5. Which unit is fixed pixels?

(a) em

(b) px

(c) %

(d) rem

► (b) px

6. Which display value shows items in a line?

(a) block

(b) inline

(c) none

(d) hidden

► (b) inline

7. Which selector targets an ID?

(a) .id

(b) #id

(c) id

(d) *id

► (b) #id

8. What does display: none; do?

(a) Hides element and removes its space

(b) Hides but keeps space

(c) Makes it transparent

(d) Adds border

► (a) Hides element and removes its space

9. How do you write a CSS comment?

(a) // comment

(b) /* comment */

(c) <!-- comment -->

(d) # comment

► (b) /* comment */

10. Which property sets the space between letters?

(a) line-height

(b) letter-spacing

(c) word-spacing

(d) text-indent

► (b) letter-spacing

11. Which rule targets <a> elements inside <nav>?

(a) nav a { ... }

(b) a nav { ... }

(c) nav > a { ... }

(d) a { nav { ... } }

► (a) nav a { ... }

12. What does gap do in flex/grid?

(a) Adds space between items

(b) Removes borders

(c) Adds padding only

(d) Changes font

► (a) Adds space between items

13. Which property controls the order of flex items?

(a) order

(b) position

(c) align

(d) float

► (a) order

14. Which media query applies to small screens?

(a) @media (min-width: 1200px)

(b) @media (max-width: 480px)

(c) @media (orientation: portrait)

(d) @font-face

► (b) @media (max-width: 480px)

15. Which selector selects all paragraphs?

(a) .p

(b) p

(c) #p

(d) *p

► (b) p

16. Which is recommended for maintainable CSS?

(a) Many long descendant selectors

(b) Small, reusable classes

(c) Inline styles everywhere

(d) Duplicate rules

► (b) Small, reusable classes

17. Which unit is relative to the current font size?

(a) px

(b) em

(c) cm

(d) mm

► (b) em

18. What is a common next step after learning basics?

(a) Learn advanced layout (Grid) and responsive patterns

(b) Stop using CSS

(c) Only learn images

(d) Learn server logs

► (a) Learn advanced layout (Grid) and responsive patterns
