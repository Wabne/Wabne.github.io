CSS

CSS (Cascading Style Sheets) controls presentation — color, spacing, layout and responsive behavior — while HTML provides structure. Good CSS starts with semantic HTML: style the meaning, not the tag. Learn selectors, the box model, specificity, and responsive units like rem and vw. In this Class 6 chapter we cover practical, copyable examples (from tiny one-line rules to a small working page). Explanations focus on why rules exist (readability, performance, accessibility) and how to keep styles maintainable.

One-line Hello (first example)

A minimal rule that you can drop into a <style> block to make headings blue.

Copied
h1 { color: blue; }

Selectors & Units

Selectors choose elements to style: tag, class, id, attribute, and combinators. Prefer classes for reuse. Use rem for scalable typography (set html { font-size }), and vw for viewport-relative sizing when needed.

Copied
:root { font-size: 16px; }
.lead { font-size: 1.25rem; }
.wide { width: 80vw; }

Box Model & Spacing

Every element has content, padding, border, and margin. Use box-sizing: border-box to make width calculations intuitive. Keep spacing consistent with variables or root sizing.

Copied
* { box-sizing: border-box; }
.card { padding: 1rem; border: 1px solid #ddd; margin: 1rem 0; }

Interactions (hover)

Pseudo-classes like :hover and :focus add simple interactivity. Keep hover effects subtle and ensure keyboard focus states exist for accessibility.

Copied
a { text-decoration: none; }
a:hover, a:focus { text-decoration: underline; }

Final Example — small working page (index.html)

The final example below shows an index.html file with inline CSS in the <head> (class 6 pattern). Save as index.html and open in a browser to see the styles applied.

index.html

Copied
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>CSS Demo</title>
  <style>
    :root { font-size: 16px; }
    * { box-sizing: border-box; font-family: Arial, sans-serif; }
    body { margin: 1rem; }
    h1 { color: #2a6f9e; }
    .card { padding: 1rem; border: 1px solid #ddd; max-width: 40rem; }
    a { color: #2a6f9e; }
    a:hover, a:focus { text-decoration: underline; }
  </style>
</head>
<body>
  <h1>CSS Basics</h1>
  <div class="card">
    <p>This demo uses inline <style> in the head, demonstrating rems, box model, and hover states.</p>
    <ul>
      <li>Responsive units: rem and vw</li>
      <li>Box-sizing for predictable layouts</li>
    </ul>
    <p>Learn to separate structure and presentation: HTML for meaning, CSS for appearance.</p>
    <p>Icon: <img src="css.png" alt="CSS icon" /></p>
  </div>
</body>
</html>

MCQs

1. Which property controls the space between an element's content and its border?

(a) margin

(b) padding

(c) border-spacing

(d) gap

► (b) padding

2. Which value for box-sizing makes width include padding and border?

(a) content-box

(b) border-box

(c) padding-box

(d) box-border

► (b) border-box

3. Which unit is relative to the root font-size and is good for scalable typography?

(a) px

(b) em

(c) rem

(d) %

► (c) rem

4. Which selector matches elements with class "card"?

(a) #card

(b) .card

(c) card

(d) <card>

► (b) .card

5. Which property sets the background color of an element?

(a) color

(b) bg

(c) background-color

(d) background-image

► (c) background-color

6. How do you make links show an underline only on hover?

(a) a { text-decoration: underline; }

(b) a:hover { text-decoration: underline; }

(c) a:focus { text-decoration: none; }

(d) a::hover { text-decoration: underline; }

► (b) a:hover { text-decoration: underline; }

7. Which property controls layout in a one-dimensional row or column?

(a) grid

(b) flex

(c) float

(d) position

► (b) flex (use display: flex)

8. What does the CSS shorthand margin: 1rem 2rem; set?

(a) top/bottom 1rem, left/right 2rem

(b) top 1rem, right 2rem, bottom 1rem, left 2rem

(c) all sides 1rem then 2rem

(d) invalid syntax

► (a) top/bottom 1rem, left/right 2rem

9. Which property would you use to create space between flex items?

(a) padding

(b) gap

(c) margin-collapse

(d) spacing

► (b) gap

10. Which of these positions removes an element from normal flow but positions it relative to its nearest positioned ancestor?

(a) static

(b) relative

(c) absolute

(d) fixed

► (c) absolute

11. Which pseudo-class targets an element that has keyboard focus?

(a) :hover

(b) :active

(c) :focus

(d) :visited

► (c) :focus

12. Which property controls the stacking order of positioned elements?

(a) order

(b) z-index

(c) stack

(d) depth

► (b) z-index

13. Which value makes an element semi-transparent?

(a) opacity: 1;

(b) opacity: 0;

(c) opacity: 0.5;

(d) transparent: true;

► (c) opacity: 0.5;

14. Which rule will apply only when the viewport is at most 600px wide?

(a) @media (min-width: 600px) { ... }

(b) @media (max-width: 600px) { ... }

(c) @media (width: 600px) { ... }

(d) @media-screen (600px) { ... }

► (b) @media (max-width: 600px) { ... }

15. Which CSS property is used to change the font weight?

(a) font-style

(b) font-size

(c) font-weight

(d) font-variant

► (c) font-weight

16. What does the selector ul li target?

(a) all ul elements

(b) li elements that are descendants of ul

(c) only direct children li of ul

(d) only the first li in ul

► (b) li elements that are descendants of ul

17. Which property controls how text wraps within an element?

(a) white-space

(b) text-wrap

(c) wrap-mode

(d) word-break only

► (a) white-space (together with word-break/overflow-wrap as needed)

18. To ensure consistent box calculations across browsers, which rule is commonly set globally?

(a) * { display: block; }

(b) * { box-sizing: border-box; }

(c) html { height: 100%; }

(d) body { margin: 0; }

► (b) * { box-sizing: border-box; }
