C#

C# is a language used to make simple programs and games. Use Console.WriteLine() to show text and dotnet run to run the program.

Hello (one line)

Copied
using System; class P{ static void Main(){ Console.WriteLine("Hi"); } }

Quick notes

  • Use Console.WriteLine() to print.
  • Use dotnet run to execute a project.
  • Try printing text and simple numbers to practice.

MCQs

1. Which prints text?

(a) Console.WriteLine()

(b) printf()

(c) echo

(d) cout

► (a) Console.WriteLine()

2. How to run a C# console project?

(a) dotnet run

(b) node run

(c) python run

(d) run

► (a) dotnet run

3. Which shows input from user?

(a) Console.ReadLine()

(b) input()

(c) read()

(d) get()

► (a) Console.ReadLine()

4. Which creates a new object?

(a) new Obj()

(b) Obj()

(c) create Obj

(d) make Obj

► (a) new Obj()

5. Which type is used for true/false?

(a) bool

(b) int

(c) string

(d) char

► (a) bool

6. Which keeps code tidy for resources?

(a) using

(b) free

(c) close

(d) release

► (a) using

7. Which holds text?

(a) string

(b) int

(c) float

(d) bool

► (a) string

8. Which is entry method?

(a) Main

(b) start

(c) run

(d) begin

► (a) Main

9. Which makes list of strings?

(a) new List<string>()

(b) ["a"]

(c) list("a")

(d) make list

► (a) new List<string>()

10. Which shows newline automatically?

(a) Console.WriteLine()

(b) Console.Write()

(c) print()

(d) echo()

► (a) Console.WriteLine()

11. Which command starts a console template?

(a) dotnet new console

(b) dotnet init

(c) new console

(d) create console

► (a) dotnet new console

12. Which is correct to print number n?

(a) Console.WriteLine(n);

(b) print(n);

(c) echo n;

(d) write(n);

► (a) Console.WriteLine(n);

13. Which keyword infers type?

(a) var

(b) let

(c) auto

(d) define

► (a) var

14. Which type holds decimals?

(a) double

(b) int

(c) string

(d) bool

► (a) double

15. Which reads one line of text?

(a) Console.ReadLine()

(b) Read()

(c) input()

(d) get()

► (a) Console.ReadLine()

16. Which shows first item of list a?

(a) a[0]

(b) a[1]

(c) a.first()

(d) a.get(0)

► (a) a[0]

17. Which is used to print a variable s?

(a) Console.WriteLine(s);

(b) print(s);

(c) echo s;

(d) cout << s;

► (a) Console.WriteLine(s);

18. Next step?

(a) Make a small program that asks name and prints greeting

(b) Stop

(c) Only HTML

(d) Play games

► (a) Make a small program that asks name and prints greeting
