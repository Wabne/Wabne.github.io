Kotlin

Kotlin is a modern, statically typed programming language that runs on the Java Virtual Machine (JVM). It is concise, safe (null-safety), and fully interoperable with Java. Kotlin reduces boilerplate code, offers useful features like data classes and extension functions, and provides coroutines for lightweight asynchronous programming. This chapter introduces Kotlin's core ideas, shows practical examples you can copy, and ends with revision MCQs.

Why Kotlin matters

Kotlin is used for Android apps, server-side services, scripting, and multiplatform projects. Because it works with existing Java libraries, teams can adopt Kotlin gradually. Its concise syntax speeds up development and its safety features reduce common runtime bugs.

Basic syntax

Source files use the .kt extension. The entry point is a main function. Types can be declared explicitly or inferred. Use val for read-only variables and var for mutable ones.

Types and variables

  • val name: String = "Anna" — read-only
  • var count: Int = 5 — mutable
  • Common types: Int, Double, String, Boolean
  • Nullable types: String? (use ?. or Elvis ?: to handle nulls)

Functions

Functions are declared with fun. Return type comes after the parameter list. Single-expression functions can be shortened.

Copied
fun add(a: Int, b: Int): Int {
  return a + b
}

// single-expression form
fun mul(a: Int, b: Int) = a * b

Data classes

Use data class for simple containers of data. Kotlin will generate useful methods like toString(), equals(), and copy().

Copied
data class Point(val x: Int, val y: Int)

val p = Point(2, 3)
val p2 = p.copy(x = 5)

Collections and loops

Build lists with listOf() (immutable) or mutableListOf() (mutable). Use for loops and collection functions (map, filter, forEach) to work with collections.

Copied
val nums = listOf(1, 2, 3, 4)
for (n in nums) {
  println(n)
}

val evens = nums.filter { it % 2 == 0 }
val squared = nums.map { it * it }

Control flow

Use if for branching and when as a powerful switch. when can return a value and match by type, value, or condition.

Copied
fun describe(x: Any): String = when(x) {
  1 -> "one"
  "hello" -> "greeting"
  is Long -> "Long number"
  else -> "unknown"
}

Null-safety

Kotlin prevents many null-pointer problems. Mark a type nullable with ?. Use safe-call ?. to access members and ?: to provide a default.

Copied
var name: String? = null
println(name?.length ?: 0) // prints 0 if name is null

Coroutines (short)

Coroutines are Kotlin’s lightweight threads for asynchronous tasks. They let you write non-blocking code in a sequential style. Typical coroutine code uses runBlocking, launch, or async and needs the kotlinx.coroutines library.

Copied
// simple example (requires kotlinx.coroutines)
import kotlinx.coroutines.*
fun main() = runBlocking {
  launch {
    delay(100)
    println(\"World\")
   }
  println(\"Hello\")
}

Tooling & building

Common tools: kotlinc (compiler), kotlin (runner), IntelliJ IDEA and Android Studio for development. To create a runnable JAR: kotlinc file.kt -include-runtime -d file.jar then java -jar file.jar.

Good practices

  • Prefer val over var for immutability.
  • Use data classes for simple data structures.
  • Use null-safety operators rather than forcing nullable casts.
  • Keep coroutine scopes lifecycle-aware (for Android) and avoid global scopes for structured concurrency.
  • Write small functions and favor expressive names.

Example — small program (combined)

Copied
data class Student(val name: String, val marks: Int)

fun topStudents(list: List<Student>): List<Student> {
  return list.filter { it.marks >= 75 }.sortedByDescending { it.marks }
}

fun main(){
  val students = listOf(Student(\"Asha\", 82), Student(\"Raju\", 68), Student(\"Maya\", 90))
  val top = topStudents(students)
  for (s in top) println(s.name + \" - \" + s.marks)
}

MCQs

1. Which keyword declares a read-only variable?

(a) var

(b) val

(c) let

(d) const

► (b) val

2. How do you define a nullable string?

(a) String?

(b) ?String

(c) String|null

(d) Nullable<String>

► (a) String?

3. Which builds an immutable list?

(a) listOf(1,2,3)

(b) mutableListOf(1,2,3)

(c) new List()

(d) arrayListOf(1,2,3)

► (a) listOf(1,2,3)

4. Which operator safely calls a method on a nullable object?

(a) ?.

(b) !.

(c) ..

(d) ::

► (a) ?.

5. How do you declare a function that returns Int?

(a) fun add(): Int { }

(b) def add() -> int

(c) int add() { }

(d) func add() int

► (a) fun add(): Int { }

6. Which makes a data holder class?

(a) data class

(b) struct

(c) record

(d) value class

► (a) data class

7. Which function creates a mutable list?

(a) mutableListOf()

(b) listOf()

(c) arrayOf()

(d) newList()

► (a) mutableListOf()

8. What does when do?

(a) Replaces if as a decision expression

(b) Declares variables

(c) Creates threads

(d) Formats strings

► (a) Replaces if as a decision expression

9. How do you print text in Kotlin?

(a) println()

(b) printline()

(c) echo()

(d) System.out.println()

► (a) println()

10. Which keyword allows mutation of a variable?

(a) var

(b) val

(c) const

(d) imm

► (a) var

11. Which standard library function returns the last element of a list?

(a) last()

(b) end()

(c) tail()

(d) finish()

► (a) last()

12. Which tool compiles Kotlin to JVM bytecode?

(a) kotlinc

(b) javac

(c) gcc

(d) python

► (a) kotlinc

13. Which operator provides a default value for nulls?

(a) ?:

(b) ??

(c) ||

(d) &&

► (a) ?:

14. Which library is commonly used for coroutines?

(a) kotlinx.coroutines

(b) java.util.concurrent

(c) android.os

(d) kotlin.io

► (a) kotlinx.coroutines

15. Which of these is a collection transformation?

(a) map

(b) sleep

(c) wait

(d) join

► (a) map

16. Which is the correct single-expression function?

(a) fun square(x: Int) = x * x

(b) fun square(x: Int) { x * x }

(c) def square(x) -> x * x

(d) func square(x) x * x

► (a) fun square(x: Int) = x * x

17. Which statement about Kotlin and Java is true?

(a) Kotlin is fully interoperable with Java

(b) Kotlin cannot call Java libraries

(c) Java code must be rewritten to use Kotlin

(d) Kotlin replaces the JVM

► (a) Kotlin is fully interoperable with Java

18. Next learning step?

(a) Practice small projects: build a console app with data classes, collections, and coroutines

(b) Stop

(c) Only HTML

(d) Paint

► (a) Practice small projects: build a console app with data classes, collections, and coroutines
