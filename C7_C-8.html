C#

C# is an object-oriented language used to build apps and games. It runs on .NET and uses clear syntax for classes, lists, and console input/output.

How to run

Create a project with dotnet new console, then use dotnet run to build and run.

Hello world (short)

Copied
using System; class P{ static void Main(){ Console.WriteLine("Hello"); } }

Small example (list)

Copied
using System; using System.Collections.Generic; class P{ static void Main(){ var a = new List<string>{ "X" }; Console.WriteLine(a[0]); } }

MCQs

1. Which prints text?

(a) printf()

(b) Console.WriteLine()

(c) echo

(d) cout

► (b) Console.WriteLine()

2. How to run a simple project?

(a) dotnet run

(b) node run

(c) python run

(d) start

► (a) dotnet run

3. Which holds text?

(a) string

(b) int

(c) bool

(d) char

► (a) string

4. Which makes a list?

(a) new List<T>()

(b) list()

(c) []

(d) make list

► (a) new List<T>()

5. Which creates an object?

(a) new Person()

(b) Person()

(c) create Person

(d) make Person

► (a) new Person()

6. Which keyword infers type?

(a) var

(b) let

(c) auto

(d) define

► (a) var

7. Which handles errors?

(a) try/catch

(b) if/error

(c) protect

(d) error()

► (a) try/catch

8. Which reads console input?

(a) Console.ReadLine()

(b) input()

(c) read()

(d) scanf()

► (a) Console.ReadLine()

9. Which creates string variable s?

(a) string s = "hi";

(b) var s = 1;

(c) s := "hi"

(d) str s = "hi";

► (a) string s = "hi";

10. Which is correct main signature?

(a) static void Main()

(b) int main()

(c) Main()

(d) program()

► (a) static void Main()

11. Which is used for lists?

(a) List<T>

(b) vector

(c) arraylist only

(d) table

► (a) List<T>

12. Which shows first item of list a?

(a) a[0]

(b) a[1]

(c) a.first()

(d) a.get(0)

► (a) a[0]

13. Which creates a console project?

(a) dotnet new console

(b) new project

(c) create console

(d) dotnet init

► (a) dotnet new console

14. Which is true about C#?

(a) It is garbage-collected

(b) It needs manual free()

(c) It cannot run on servers

(d) It is only for styling

► (a) It is garbage-collected

15. Which type holds whole numbers?

(a) int

(b) float

(c) string

(d) char

► (a) int

16. Which shows newline after printing?

(a) Console.WriteLine()

(b) Console.Write()

(c) print()

(d) echo()

► (a) Console.WriteLine()

17. Which keyword marks program entry?

(a) Main

(b) Start

(c) Begin

(d) Run

► (a) Main

18. Next step?

(a) Build a small console app with input and lists

(b) Stop

(c) Only HTML

(d) Paint

► (a) Build a small console app with input and lists
