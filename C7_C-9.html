Java

Java is an object-oriented language that runs on the JVM. This version focuses on practical examples and shorter explanations suitable for quick classroom use.

How to run

Save as Main.java, compile with javac Main.java, run with java Main. Use an IDE or simple text editor plus terminal.

Hello world (short)

Copied
public class Main{ public static void main(String[] args){ System.out.println("Hello"); } }

Short example (array loop)

Copied
public class Main2{ public static void main(String[]args){ int[] a={1,2,3}; for(int x:a) System.out.println(x); } }

MCQs (short)

1. Which compiles Java?

(a) javac

(b) java

(c) gcc

(d) node

► (a) javac

2. Which runs Java bytecode?

(a) java

(b) javac

(c) python

(d) node

► (a) java

3. Which prints line?

(a) System.out.println()

(b) print()

(c) echo()

(d) printf()

► (a) System.out.println()

4. File name for public class Main?

(a) Main.java

(b) main.txt

(c) Main.class

(d) Main.py

► (a) Main.java

5. Which holds numbers?

(a) int

(b) string

(c) bool

(d) char

► (a) int

6. Which creates array of ints?

(a) int[] a = {1,2};

(b) a = [1,2]

(c) new array()

(d) make array

► (a) int[] a = {1,2};

7. Which loop iterates through array?

(a) for (int x : a)

(b) foreach a

(c) repeat

(d) while only

► (a) for (int x : a)

8. Which package contains String?

(a) java.lang

(b) java.util

(c) java.io

(d) java.net

► (a) java.lang

9. Which is entry method name?

(a) main

(b) start

(c) run

(d) init

► (a) main

10. Which creates object?

(a) new ClassName()

(b) ClassName()

(c) make ClassName

(d) create ClassName

► (a) new ClassName()

11. Which stores text?

(a) String

(b) int

(c) float

(d) boolean

► (a) String

12. Which is correct array loop?

(a) for (int x : a)

(b) for x in a

(c) each(a)

(d) iterate a

► (a) for (int x : a)

13. Which makes program file?

(a) Save as .java

(b) Save as .py

(c) Save as .txt

(d) Save as .class

► (a) Save as .java

14. Which prints value n?

(a) System.out.println(n);

(b) print(n);

(c) echo n;

(d) println n;

► (a) System.out.println(n);

15. Which type holds decimals?

(a) double

(b) int

(c) String

(d) boolean

► (a) double

16. Which is used to handle errors?

(a) try/catch

(b) if/else

(c) loop

(d) switch

► (a) try/catch

17. Which method signature prints hello?

(a) public static void main(String[] args)

(b) public void start()

(c) int main()

(d) void run()

► (a) public static void main(String[] args)
