PHP

PHP is a server-side scripting language designed for web development and general-purpose programming. It runs on a web server, processes requests, and generates HTML to send to the browser. PHP is commonly used to build dynamic pages, handle form data, work with databases, and create APIs.

How PHP is used

PHP code is embedded in HTML or executed as standalone scripts on the server. When a browser requests a PHP page, the server runs the PHP code and returns the resulting HTML. PHP is often paired with a database (for example MySQL) to store and retrieve data.

Key features

  • Server-side execution — runs on the web server before sending results to the browser
  • Easy to embed in HTML — simple syntax for outputting content
  • Built-in support for many databases and common tasks
  • Large ecosystem of libraries and frameworks

Simple structure & Hello world

Copied
<?php
  $greeting = "Hello, world!";
  echo $greeting;
?>

Short examples (variables, function, DB hint)

Copied
<?php
  function sum($a, $b){
    return $a + $b;
  }
  echo sum(3,4); // prints 7
?>

Where PHP runs

PHP runs on the server (Apache, Nginx, or built-in server). It can also be used from the command line for scripts and automation.

Good practices

  • Validate and sanitize user input before using it
  • Use prepared statements for database queries
  • Keep configuration (credentials) out of public web folders
  • Use error logging and avoid showing raw errors to users

MCQs

1. What kind of language is PHP?

(a) Client-side scripting

(b) Server-side scripting

(c) Markup language

(d) Styling language

► (b) Server-side scripting

2. Which tag starts PHP code in a file?

(a) <php>

(b) <?php

(c) <script>

(d) <!-- php -->

► (b) <?php

3. How do you print text in PHP?

(a) print("text")

(b) echo "text";

(c) console.log("text")

(d) write("text")

► (b) echo "text";

4. Which structure holds key:value pairs in PHP?

(a) array

(b) object

(c) associative array

(d) tuple

► (c) associative array

5. Which function adds two numbers in the example?

(a) add()

(b) sum()

(c) plus()

(d) total()

► (b) sum()

6. How is PHP executed for web pages?

(a) In the browser

(b) On the server

(c) In CSS files

(d) In image files

► (b) On the server

7. Which symbol begins a comment in PHP (single line)?

(a) //

(b) #

(c) /* */

(d) Both (a) and (b)

► (d) Both (a) and (b)

8. What should you use to prevent SQL injection?

(a) String concatenation

(b) Prepared statements

(c) Echo user input

(d) Disable database

► (b) Prepared statements

9. Which function returns the length of a string?

(a) size()

(b) strlen()

(c) length()

(d) count()

► (b) strlen()

10. Which keyword declares a function?

(a) func

(b) function

(c) def

(d) fn

► (b) function

11. Which array type uses numeric indexes?

(a) associative array

(b) indexed array

(c) map

(d) object

► (b) indexed array

12. How does PHP send output to the browser?

(a) By returning JSON only

(b) By printing HTML from server-side code

(c) By changing CSS files

(d) By sending images only

► (b) By printing HTML from server-side code

13. Which built-in server can you use for testing in PHP 5.4+?

(a) Apache only

(b) Built-in PHP server (php -S)

(c) Nginx only

14. Which keyword defines a constant in PHP (since 5.3)?

(a) var
