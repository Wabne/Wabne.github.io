C++

C++ is a programming language used to make programs and simple games. It extends C with features that help organize code into classes and use ready-made containers.

Hello (one line)

Copied
#include <iostream>
int main(){ std::cout << "Hi\\n"; }

Things to remember

  • Use std::cout << to print text.
  • Save files as .cpp and compile with g++ file.cpp -o program.
  • Try small examples: print values, add numbers, and use a vector for lists.

MCQs

1. Which prints text?

(a) print()

(b) std::cout

(c) echo

(d) printf()

► (b) std::cout

2. Which file ends source code?

(a) .cpp

(b) .py

(c) .c

(d) .html

► (a) .cpp

3. Which compiles C++?

(a) g++

(b) node

(c) python

(d) php

► (a) g++

4. How to run program?

(a) ./program

(b) node program

(c) run program

(d) start program

► (a) ./program

5. Which header for I/O?

(a) <iostream>

(b) <io>

(c) <print>

(d) <console>

► (a) <iostream>

6. Which symbol prints value?

(a) <<

(b) >>

(c) ++

(d) --

► (a) <<

7. How to include vector?

(a) #include <vector>

(b) include vector

(c) import vector

(d) using vector

► (a) #include <vector>

8. Which stores text?

(a) std::string

(b) int

(c) float

(d) bool

► (a) std::string

9. Which makes a function?

(a) int sum(int a,int b){}

(b) function sum() {}

(c) def sum():

(d) create sum()

► (a) int sum(int a,int b){}

10. Which returns from main?

(a) return 0;

(b) stop;

(c) end;

(d) finish;

► (a) return 0;

11. Which is a container for many items?

(a) std::vector

(b) int

(c) float

(d) char

► (a) std::vector

12. Which prints newline with cout?

(a) << std::endl

(b) << "\\n"

(c) <br>

(d) newline()

► (a) << std::endl

13. Which creates a vector with values?

(a) std::vector<int> v = {1,2};

(b) vector v = [1,2]

(c) v = (1,2)

(d) list(1,2)

► (a) std::vector<int> v = {1,2};

14. Which keyword starts a C++ program?

(a) int main()

(b) start()

(c) begin()

(d) run()

► (a) int main()

15. Which type holds numbers without decimals?

(a) int

(b) float

(c) double

(d) string

► (a) int

16. How to compile file.cpp?

(a) g++ file.cpp -o program

(b) node file.cpp

(c) python file.cpp

(d) run file.cpp

► (a) g++ file.cpp -o program

17. Which prints two numbers a and b?

(a) std::cout << a << " " << b << std::endl;

(b) print(a,b)

(c) echo a b

(d) printf("%d %d", a, b);

► (a) std::cout << a << " " << b << std::endl;

18. Next step?

(a) Try small programs with functions and vectors

(b) Stop

(c) Only CSS

(d) Paint

► (a) Try small programs with functions and vectors
