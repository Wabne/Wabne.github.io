C

C is a fast, low-level language used to write programs that need performance or direct hardware access. You write code, compile it, and run the resulting program. This version keeps explanations short and practical.

How C works

Write a .c file, compile with a compiler like gcc, then run the produced executable. C programs use headers for library functions.

Hello world (short)

Copied
#include <stdio.h>
int main(void) {
  printf("Hello\\n");
  return 0;
}

Small example (loop)

Copied
#include <stdio.h>
int main(void) { int i; for (i = 0; i < 3; ++i) printf("%d\\n", i); return 0; }

MCQs

1. Which prints text in C?

(a) cout

(b) printf()

(c) echo

(d) print()

► (b) printf()

2. Which tool compiles C?

(a) python

(b) gcc

(c) node

(d) browser

► (b) gcc

3. How many times does for(i=0;i<3;i++) run?

(a) 2

(b) 3

(c) 4

(d) 1

► (b) 3

4. Which header for I/O?

(a) <stdio.h>

(b) <math.h>

(c) <string.h>

(d) <time.h>

► (a) <stdio.h>

5. What returns from main?

(a) return 0;

(b) stop()

(c) end()

(d) quit()

► (a) return 0;

6. Which is an integer type?

(a) int

(b) float

(c) double

(d) char

► (a) int

7. Which loop runs while condition is true?

(a) while

(b) for

(c) repeat

(d) foreach

► (a) while

8. Which includes library?

(a) #include

(b) import

(c) require

(d) use

► (a) #include

9. Which shows a char?

(a) %d

(b) %c

(c) %s

(d) %f

► (b) %c

10. Which stores text in C?

(a) char array

(b) int

(c) float

(d) bool

► (a) char array

11. Which reads input?

(a) scanf()

(b) input()

(c) read()

(d) get()

► (a) scanf()

12. Which stops program immediately?

(a) exit(0)

(b) return 0

(c) quit()

(d) stop()

► (a) exit(0)

13. Which is correct main signature?

(a) int main(void)

(b) main()

(c) program()

(d) start()

► (a) int main(void)

14. Which prints numbers?

(a) printf("%d", n);

(b) print(n);

(c) echo n;

(d) cout << n;

► (a) printf("%d", n);

15. Which function adds two ints (example)?

(a) int add(int a,int b){return a+b;}

(b) add(a,b)

(c) sum(a,b)

(d) plus(a,b)

► (a) int add(int a,int b){return a+b;}

16. Which frees memory?

(a) free()

(b) delete

(c) remove()

(d) clear()

► (a) free()

17. Which header for string functions?

(a) <string.h>

(b) <stdio.h>

(c) <stdlib.h>

(d) <math.h>

► (a) <string.h>

18. Next step?

(a) Learn arrays and pointers

(b) Stop

(c) Only styling

(d) Draw

► (a) Learn arrays and pointers
