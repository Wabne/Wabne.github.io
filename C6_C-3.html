JavaScript

JavaScript makes pages do things. It can show messages, run simple math, and respond when a button is clicked. Start with small scripts and try examples in the browser console.

Very simple examples

Copied
console.log("Hello world");
alert("Hi");

Basic ideas

  • Variables: store a number or text (let n = 2;).
  • Functions: small named actions you can run.
  • Events: run code when the user clicks a button.

Small DOM example

Copied
const btn = document.getElementById("btn");
btn.addEventListener("click", ()=>{ alert("Button clicked"); });

Tips

  • Try code in the browser console.
  • Start with console.log to check values.

MCQs

1. Which shows a message in console?

(a) alert()

(b) console.log()

(c) print()

(d) show()

► (b) console.log()

2. Which makes a pop-up box?

(a) console.log()

(b) alert()

(c) message()

(d) notify()

► (b) alert()

3. Which gets an element by id?

(a) getId()

(b) document.getElementById()

(c) findId()

(d) idOf()

► (b) document.getElementById()

4. How to write a function?

(a) function name() { }

(b) def name() { }

(c) create name() { }

(d) set name() { }

► (a) function name() { }

5. What stores text?

(a) number

(b) string

(c) boolean

(d) object

► (b) string

6. Which is used to run code on click?

(a) addEventListener("click", ...)

(b) onClick = false

(c) clickNow()

(d) doClick()

► (a) addEventListener("click", ...)

7. Which shows type of value?

(a) typeof

(b) type()

(c) whatis()

(d) kindOf()

► (a) typeof

8. Which is a loop?

(a) for

(b) if

(c) func

(d) var

► (a) for

9. Which is true/false type?

(a) string

(b) number

(c) boolean

(d) array

► (c) boolean

10. How to add text to page using JS?

(a) document.write()

(b) console.log()

(c) alert()

(d) prompt()

► (a) document.write()

11. Which makes a list of values?

(a) object

(b) array

(c) string

(d) number

► (b) array

12. Which is used to stop a loop?

(a) end

(b) break

(c) stop

(d) finish

► (b) break

13. Which gets first item of array a?

(a) a[0]

(b) a.first()

(c) a.get(0)

(d) a.item(1)

► (a) a[0]

14. Which shows a small input box?

(a) alert()

(b) prompt()

(c) confirm()

(d) console.log()

► (b) prompt()

15. How to join text pieces?

(a) add()

(b) + operator

(c) join()

(d) merge()

► (b) + operator

16. Which converts text '7' to number 7?

(a) parseInt('7')

(b) toNumber('7')

(c) number('7')

(d) cast('7')

► (a) parseInt('7')

17. Which is true about functions?

(a) They cannot return values

(b) They can return values

(c) They must be named 'do'

(d) They are only for math

► (b) They can return values

18. What to try after these basics?

(a) Learn how to use events and small interactions

(b) Stop learning

(c) Only draw pictures

(d) Learn cooking

► (a) Learn how to use events and small interactions
