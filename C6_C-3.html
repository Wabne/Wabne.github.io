JavaScript

JavaScript is the programming language of the web — it brings pages to life by manipulating HTML, responding to user actions, and performing logic in the browser. Unlike HTML (structure) and CSS (presentation), JavaScript controls behavior: reading values, changing content, validating input, and handling events. In this Class 6 chapter we focus on readable, beginner-friendly examples: printing output, selecting DOM elements, adding event listeners, writing small functions, and a final working subtraction page that uses clear variable names (minuend, subtrahend, difference).

Getting started

Run JavaScript in the browser console or include it inside a <script> block. Use console.log() to print values while learning. Prefer descriptive variable and function names — they make code self-documenting and easier to debug.

Hello World

Copied
console.log("Hello, world!");

Selecting elements (DOM)

Use document.querySelector and document.querySelectorAll to find elements. Change text with textContent or modify attributes with setAttribute.

Copied
const title = document.querySelector("h1");
title.textContent = "Hello from JavaScript";

Event listeners

Listen for user actions with addEventListener. Keep handlers small and call named functions for clarity. Always validate input before using values in calculations.

Copied
const btn = document.querySelector("#calc");
btn.addEventListener("click", handleClick);
function handleClick() { console.log("Button clicked"); }

Small function example

Write reusable functions with clear inputs and outputs. Use Number() to convert strings to numbers before arithmetic to avoid unexpected results.

Copied
function add(a, b) { return Number(a) + Number(b); }
console.log(add(2, 3)); // 5

Final Example — subtraction with minuend/subtrahend/difference

The final example follows the Class 6 pattern: a single index.html file that includes inline <script defer> in the <head>. It shows two inputs, a button, and a result area. Variable names are clear: minuend, subtrahend, and difference. Save as index.html and open in a browser.

index.html

Copied
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Subtract Demo</title>
  <script defer>
    function calculateDifference() {
      const minuend = Number(document.querySelector("#minuend").value);
      const subtrahend = Number(document.querySelector("#subtrahend").value);
      const difference = minuend - subtrahend;
      document.querySelector("#result").textContent = "Difference: " + difference;
    }
  </script>
</head>
<body>
  <h1>Subtract Two Numbers</h1>
  <label>Minuend: <input id="minuend" type="number" /></label><br />
  <label>Subtrahend: <input id="subtrahend" type="number" /></label><br />
  <button id="calc" type="button" onclick="calculateDifference()">Calculate</button>
  <div id="result">Difference: </div>
</body>
</html>

MCQs

1. Which JavaScript statement prints text to the browser console?

(a) print("Hello")

(b) console.log("Hello")

(c) echo "Hello"

(d) document.write("Hello")

► (b) console.log("Hello")

2. Which of these correctly selects the first <h1> element in the document?

(a) document.getElementsByTagName("h1")

(b) document.querySelector("h1")

(c) document.querySelectorAll("h1")[0]

(d) All of the above

► (d) All of the above

3. What does Number("3") return?

(a) "3"

(b) 3

(c) NaN

(d) undefined

► (b) 3

4. Which event method attaches a listener without replacing others?

(a) onclick = fn

(b) element.addEventListener("click", fn)

(c) element.on("click", fn)

(d) element.attach("click", fn)

► (b) element.addEventListener("click", fn)

5. Which keyword creates a block-scoped variable?

(a) var

(b) let

(c) const

(d) Both (b) and (c)

► (d) Both (b) and (c)

6. What is the result of typeof NaN?

(a) "number"

(b) "NaN"

(c) "undefined"

(d) "object"

► (a) "number"

7. Which operator checks both value and type?

(a) ==

(b) =

(c) ===

(d) !=

► (c) ===

8. Where should a <script defer> tag be placed for correct deferred execution?

(a) Inside <head>

(b) Inside <body> at the top

(c) Inside <footer>

(d) It must be in an external file only

► (a) Inside <head>

9. What does element.textContent do?

(a) Returns and sets HTML markup inside an element

(b) Returns and sets only the text content (no HTML parsing)

(c) Styles the element's text

(d) Removes the element

► (b) Returns and sets only the text content (no HTML parsing)

10. Which conversion turns "08" reliably into number 8 in modern JS?

(a) parseInt("08")

(b) parseInt("08", 10)

(c) Number("08")

(d) Both (b) and (c)

► (d) Both (b) and (c)

11. Which method prevents a form submission’s default navigation so you can handle it in JS?

(a) event.stopPropagation()

(b) event.preventDefault()

(c) return false

(d) event.cancel()

► (b) event.preventDefault()

12. Which value is considered falsy in JavaScript?

(a) 0

(b) "" (empty string)

(c) null

(d) All of the above

► (d) All of the above

13. What is the correct way to define a function that returns the sum of two numbers?

(a) function sum(a, b) { return a + b; }

(b) def sum(a, b): return a + b

(c) let sum = (a, b) => a + b;

(d) Both (a) and (c)

► (d) Both (a) and (c)

14. Which selector returns an element by its id?

(a) document.querySelector(".myId")

(b) document.getElementById("myId")

(c) document.querySelector("#myId")

(d) Both (b) and (c)

► (d) Both (b) and (c)

15. If a variable is declared without var, let, or const, what happens in non-strict mode?

(a) It becomes a global variable

(b) It throws an error

(c) It is block-scoped

(d) It is deleted

► (a) It becomes a global variable

16. Which of the following returns true for arrays?

(a) typeof [] === "array"

(b) Array.isArray([])

(c) [] instanceof Object === false

(d) [].length === undefined

► (b) Array.isArray([])

17. Which statement best describes console.error()?

(a) It logs messages with error severity to the console.

(b) It stops execution immediately.

(c) It sends an alert popup to the user.

(d) It formats code automatically.

► (a) It logs messages with error severity to the console.

18. Which approach is best to keep DOM event handlers small and testable?

(a) Put all logic directly inside anonymous handlers

(b) Call small named functions from handlers and keep handlers thin

(c) Use inline onclick attributes for everything

(d) Avoid using functions at all

► (b) Call small named functions from handlers and keep handlers thin
