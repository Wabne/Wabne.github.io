HTML

HTML helps us make simple web pages.

Short intro

HTML uses tags like <h1> and <p> to show headings and paragraphs.

Small example

Copied
<!doctype html>
<html><body><h1>Hi</h1><p>My page</p></body></html>

Tags to know

  • <h1> — heading
  • <p> — paragraph

CSS link

Copied
<link rel="stylesheet" href="style.css">

MCQs

1. Which tag makes a heading?

(a) <p>

(b) <h1>

(c) <img>

(d) <div>

► (b) <h1>

2. Which tag is for paragraphs?

(a) <p>

(b) <h2>

(c) <ul>

(d) <img>

► (a) <p>

3. How do you show a break line?

(a) <br>

(b) <hr>

(c) <break>

(d) <lb>

► (a) <br>

4. Which tag contains visible page content?

(a) <head>

(b) <body>

(c) <meta>

(d) <title>

► (b) <body>

5. Which tag is used for lists?

(a) <img>

(b) <ul>

(c) <h1>

(d) <title>

► (b) <ul>

6. Which tag is used in head for mobile?

(a) <meta name="viewport">

(b) <body>

(c) <img>

(d) <div>

► (a) <meta name="viewport">

7. What do you add to style a page?

(a) JavaScript

(b) CSS

(c) Images

(d) Links

► (b) CSS

8. Which tag is used to include CSS file?

(a) <script>

(b) <link rel="stylesheet">

(c) <style>

(d) <css>

► (b) <link rel="stylesheet">

9. Which tag starts an HTML file?

(a) <!doctype html>

(b) <html>

(c) <head>

(d) <body>

► (a) <!doctype html>

10. Which tag shows a horizontal line?

(a) <hr>

(b) <br>

(c) <line>

(d) <rule>

► (a) <hr>

11. Which tag is used for a block container?

(a) <span>

(b) <div>

(c) <img>

(d) <p>

► (b) <div>

12. Which tag is for small text emphasis?

(a) <em>

(b) <b>

(c) <i>

(d) <strong>

► (a) <em>

13. How to show code in HTML page?

(a) <code>

(b) <program>

(c) <script>

(d) <pre>

► (a) <code>

14. Which tag is for site header?

(a) <header>

(b) <head>

(c) <h1>

(d) <title>

► (a) <header>

15. Which tag adds a blank line?

(a) <br>

(b) <hr>

(c) <space>

(d) <linebreak>

► (a) <br>

16. Which attribute is used for alternative text on images?

(a) src

(b) alt

(c) title

(d) caption

► (b) alt

17. Which tag do you use for a list item?

(a) <li>

(b) <ul>

(c) <ol>

(d) <list>

► (a) <li>

18. Which element groups the whole page?

(a) <html>

(b) <body>

(c) <head>

(d) <div>

► (a) <html>
