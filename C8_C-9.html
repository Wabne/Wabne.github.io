Java

Java is a class-based, object-oriented programming language designed to be platform-independent. Java code is compiled to bytecode and runs on the Java Virtual Machine (JVM), so the same program can run on many operating systems without change. Java is widely used for large applications, Android apps, web backends, and enterprise systems.

How Java is used

Write source files with .java extension, compile using javac to produce bytecode (.class files), then run with the JVM: javac Main.java and java Main. Java provides a large standard library and strong tooling for building, testing, and packaging applications.

Key features

  • Object-oriented: classes, objects, inheritance, interfaces
  • Platform independence via JVM and bytecode
  • Automatic memory management (garbage collection)
  • Rich standard library (collections, I/O, concurrency)
  • Strong static typing and exception handling

Where Java runs

Java runs wherever a compatible JVM is available (desktop, servers, cloud, Android uses a related runtime). Tools: javac to compile, java to run, build tools like maven or gradle for larger projects.

Good practices

  • Follow class and package conventions: one public class per file named after the file.
  • Use exceptions for error handling and close resources with try-with-resources.
  • Prefer collections from java.util rather than raw arrays for flexible code.
  • Write small methods and document public APIs with clear names and comments inside code when needed.
