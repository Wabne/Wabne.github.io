C++

C++ is a language that lets you write fast programs and use objects (classes) to group data and behavior. This version keeps explanations practical and hands-on with examples you can try quickly.

How to run

Save a .cpp file and compile: g++ file.cpp -o program then run ./program. Use an editor or IDE for easier editing and building.

Hello world (short)

Copied
#include <iostream>
int main(){ std::cout << "Hello C++\\n"; return 0; }

Short examples (function, vector)

Copied
#include <iostream>
#include <vector>
int sum(int a,int b){ return a+b; }
int main(){
  std::vector<int> v={1,2,3};
  std::cout << sum(v[0], v[1]) << std::endl;
  return 0;
}

MCQs

1. Which prints text?

(a) print()

(b) std::cout

(c) echo

(d) printf()

► (b) std::cout

2. Which file extension for C++ source?

(a) .cpp

(b) .py

(c) .c

(d) .html

► (a) .cpp

3. Which compiles C++?

(a) g++

(b) node

(c) php

(d) python

► (a) g++

4. Which includes vector?

(a) <vector>

(b) <list>

(c) <map>

(d) <set>

► (a) <vector>

5. How to return from main?

(a) return 0;

(b) exit;

(c) stop()

(d) quit()

► (a) return 0;

6. Which adds two ints (example)?

(a) int sum(int a,int b){return a+b;}

(b) add(a,b)

(c) plus(a,b)

(d) sum(a,b)

► (a) int sum(int a,int b){return a+b;}

7. Which creates a vector of ints?

(a) std::vector<int> v;

(b) vector v;

(c) int[] v;

(d) list<int> v;

► (a) std::vector<int> v;

8. Which streams operator prints value?

(a) <<

(b) >>

(c) ++

(d) --

► (a) <<

9. Which header for I/O?

(a) <iostream>

(b) <stdio.h>

(c) <io>

(d) <console>

► (a) <iostream>

10. Which constructs element at end?

(a) emplace_back

(b) push_front

(c) pop_back

(d) remove

► (a) emplace_back

11. Which returns array element v[0]?

(a) first element

(b) v[1]

(c) v.front()

(d) get(0)

► (a) first element

12. Which keyword begins a class?

(a) class

(b) struct

(c) object

(d) module

► (a) class

13. Which is used for container algorithms?

(a) <algorithm>

(b) <util>

(c) <container>

(d) <sort>

► (a) <algorithm>

14. Which returns size of vector v?

(a) v.size()

(b) v.length()

(c) size(v)

(d) len(v)

► (a) v.size()

15. Which type holds text?

(a) std::string

(b) char

(c) int

(d) float

► (a) std::string

16. How to include iostream?

(a) #include <iostream>

(b) include iostream

(c) import iostream

(d) using iostream

► (a) #include <iostream>

17. Which runs compiled program?

(a) ./program

(b) node program

(c) run program

(d) start program

► (a) ./program

18. Next step?

(a) Learn basic classes and STL usage

(b) Stop

(c) Only HTML

(d) Paint

► (a) Learn basic classes and STL usage
