JavaScript

JavaScript is the programming language used to make web pages interactive. It runs in the browser and can change page content, respond to user actions, and communicate with servers. Learning JavaScript enables dynamic behavior, form validation, simple games, and interactive apps.

Why JavaScript matters

JavaScript adds behavior to HTML and CSS. It can read and change the DOM (page structure), handle events (clicks, typing), perform calculations, and fetch data from servers. Together with HTML and CSS, JavaScript completes the core web platform.

Linking JavaScript

Copied
<!-- place before </body> -->
  <script src="script.js"></script>

Basic building blocks

  • Variables — store values. Use let and const.
  • Types — numbers, strings, booleans, null, undefined, arrays, objects.
  • Operators — arithmetic (+, -), comparison (==, ===), logical (&&, ||).
  • Control flow — if, else, switch, loops (for, while).
  • Functions — reusable code blocks: function declaration and arrow functions.

Example: variables, condition and function

Copied
let score = 8;
function checkPass(s){
  if(s >= 5){
    console.log("Pass");
  }else{
    console.log("Fail");
  }
}
checkPass(score);

Arrays & Objects

Arrays hold ordered lists. Objects hold named properties. Both are used heavily for data and state.

Copied
let nums = [1,2,3];
let person = { name: "A", age: 14 };
console.log(nums[0], person.name);

DOM basics & events

The DOM represents page elements. JavaScript can query and change DOM nodes and attach event listeners for clicks, input, and more.

Copied
const btn = document.getElementById("btn");
btn.addEventListener("click", function(){
  alert("Clicked");
});

Console & debugging

Use console.log() to inspect values and browser DevTools to debug errors and step through code.

Good practices

  • Use let/const (avoid global vars).
  • Give functions clear names and small responsibilities.
  • Keep DOM queries and event handling organized.

What’s next

After basics, learn asynchronous JavaScript (callbacks, promises, async/await), and how to fetch data from servers (Fetch API).

MCQs

1. Which tag loads a JavaScript file?

(a) <link>

(b) <script>

(c) <style>

(d) <javascript>

► (b) <script>

2. Which keyword declares a block-scoped variable?

(a) var

(b) let

(c) def

(d) set

► (b) let

3. How do you print to the browser console?

(a) print()

(b) console.log()

(c) echo()

(d) debug()

► (b) console.log()

4. Which operator checks strict equality?

(a) ==

(b) =

(c) ===

(d) =>

► (c) ===

5. How do you define a function?

(a) func my(){}

(b) function my(){}

(c) def my(){}

(d) create my(){}

► (b) function my(){}

6. Which data structure uses key:value pairs?

(a) Array

(b) Object

(c) String

(d) Number

► (b) Object

7. Which method adds an event listener?

(a) add()

(b) on()

(c) addEventListener()

(d) listen()

► (c) addEventListener()

8. What does array.length return?

(a) Last item

(b) Number of items

(c) First item

(d) Undefined

► (b) Number of items

9. Which value means 'no value'?

(a) 0

(b) null

(c) ""

(d) false

► (b) null

10. Which loop is best when count is known?

(a) for

(b) while

(c) do...while

(d) repeat

► (a) for

11. What is returned by a function without 'return'?

(a) 0

(b) undefined

(c) null

(d) false

► (b) undefined

12. Which is an arrow function?

(a) (x) => x * 2

(b) function(x) { return x * 2 }

(c) def (x) { x * 2 }

(d) fn(x) => x * 2

► (a) (x) => x * 2

13. Which is used to fetch data from a URL?

(a) Fetch API

(b) getJSON only

(c) load()

(d) import()

► (a) Fetch API

14. Which keyword creates a constant?

(a) let

(b) const

(c) var

(d) constant

► (b) const

15. What does document.getElementById return?

(a) A list

(b) A single element or null

(c) Undefined

(d) A promise

► (b) A single element or null

16. Which type converts text to a number?

(a) parseInt()

(b) toNumber()

(c) number()

(d) int()

► (a) parseInt()

17. Which object holds browser timing functions like setTimeout?

(a) window

(b) document

(c) console

(d) navigator

► (a) window

18. What is the next topic after basics?

(a) Asynchronous JavaScript (Promises and async/await)

(b) Styling only

(c) Image editing

(d) Nothing

► (a) Asynchronous JavaScript (Promises and async/await)
